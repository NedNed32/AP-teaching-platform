Where you declare a variable decides where you can use it.

## Levels of scope

| Declared | Usable |
| --- | --- |
| as an instance (or static) variable | in every method of the class |
| as a parameter | inside that method |
| inside a method | from the declaration to the end of the method |
| inside a block (`if`, loop) | from the declaration to the end of that block |

```java
public int sumTo(int n) {
    int total = 0;              // method scope
    for (int i = 1; i <= n; i++) {
        int sq = i * i;         // block scope
        total += sq;
    }
    // i and sq do not exist here
    return total;
}
```

## Shadowing

If a parameter or local variable has the same name as an instance variable, the local one wins inside its scope. Use `this.name` to reach the instance variable (topic 3.9).

<Note title="Declare where you need it">
Declaring a running total inside a loop resets it every pass. Declare accumulators before the loop.
</Note>

<WorkedExample title="Which line fails to compile?">
```java
public void demo() {
    int a = 1;
    if (a > 0) {
        int b = 2;
        a += b;
    }
    System.out.println(a + b);
}
```

1. `a` is in scope throughout the method.
2. `b` was declared inside the if block and is out of scope at the print.

**Answer:** the println line, because `b` cannot be used there.
</WorkedExample>

**Q.** The class `Student` has a private instance variable `int grade` and a public, non-static method `int getGrade()` that returns it. A client class declares `Student s = new Student();`. Which statement in the client class compiles without error?

**A.** `int v = s.getGrade();`. Clients use public methods on an object to read private data. Private members are visible only inside Student. The client must call the public instance method `getGrade()` on an object.
