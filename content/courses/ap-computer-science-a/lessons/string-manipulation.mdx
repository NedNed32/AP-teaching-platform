Strings are objects, and the String class provides methods to examine and build them. Indexes start at **0**.

## Methods on the Java Quick Reference

| Method | Result for `s = "galaxy"` |
| --- | --- |
| `s.length()` | 6 |
| `s.substring(2)` | `"laxy"` |
| `s.substring(1, 4)` | `"ala"` |
| `s.indexOf("a")` | 1 |
| `s.indexOf("z")` | -1 |
| `s.equals("Galaxy")` | false (case matters) |
| `s.compareTo("gamma")` | negative ("gal" comes before "gam") |

A single character is a one-letter substring: `s.substring(i, i + 1)`.

## Immutability

```java
String a = "cat";
a.toUpperCase();      // returns "CAT" but a is unchanged
a = a + "s";          // a now refers to a new String "cats"
```

## Out of bounds

`s.substring(2, 9)` on a 6-character string throws a `StringIndexOutOfBoundsException`. The last valid index is `length() - 1`, while the end argument of substring may equal `length()`.

<Note title="The end index is exclusive">
`substring(a, b)` has length `b - a`. That rule makes most substring questions quick.
</Note>

<WorkedExample title="Building with substring">
What is printed?

```java
String w = "programming";
String r = w.substring(3, 7) + w.substring(w.indexOf("m"));
System.out.println(r);
```

1. `w.substring(3, 7)` is `"gram"` (indexes 3 to 6).
2. `indexOf("m")` is 6; `substring(6)` is `"mming"`.

**Answer:** `grammming`.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Consider the following code segment.

```java
String s = "painting";
String t = s.substring(3, 5);
System.out.println(t + t.length());
```

What is printed as a result of executing the code segment?

**Answer:** `nt2`

**Why:** substring(3, 5) takes indexes 3 through 4.

**Working:** Indexes 3 to 4 of "painting" give "nt", whose length is 2.

**Mistakes to avoid**

- `nti3`: The end index is exclusive.
- `ti2`: Indexes start at 0, not 1.
- `nt3`: The length of t is end minus start.

### Worked exam question 2

Consider the following code segment.

```java
String s = "painting";
int i = s.indexOf("a");
System.out.println(s.substring(i + 1) + i);
```

What is printed as a result of executing the code segment?

**Answer:** `inting1`

**Why:** indexOf returns the first position of "a", which is 1.

**Working:** "a" first appears at index 1, so the substring from 2 is "inting" and 1 is appended.

**Mistakes to avoid**

- `nting2`: indexOf counts from 0.
- `ainting1`: substring(i + 1) starts after the found letter.
- `inting2`: i itself is printed, not i + 1.

**Q.** Consider the following code segment. ```java String a = "variable"; a.substring(2); String b = a.toUpperCase(); System.out.println(a + " " + b); ``` What is printed as a result of executing the code segment?

**A.** `variable VARIABLE`. Strings are immutable; calling a method without storing its result changes nothing. String methods return new Strings. Unless the result is assigned, the original variable is unchanged.
