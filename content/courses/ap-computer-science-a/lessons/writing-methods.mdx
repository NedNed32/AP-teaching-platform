Methods give a class its behavior. Most fall into a few categories.

## Accessors and mutators

```java
public class Account {
    private double balance;

    public double getBalance() {          // accessor
        return balance;
    }

    public void deposit(double amt) {     // mutator
        if (amt > 0) {
            balance += amt;
        }
    }
}
```

## Methods that compute

```java
public boolean canAfford(double price) {
    return balance >= price;
}
```

## toString

```java
public String toString() {
    return "Account with balance " + balance;
}
```

Printing an object or concatenating it with a String calls `toString` automatically.

<Note title="Instance methods see instance variables">
Inside an instance method you can use the object's instance variables directly by name. Each call works on the object the method was called on.
</Note>

<WorkedExample title="Writing a method">
Write a method for `Account` that withdraws an amount only if the balance is large enough, returning true if the withdrawal happened.

```java
public boolean withdraw(double amt) {
    if (amt <= balance) {
        balance -= amt;
        return true;
    }
    return false;
}
```

**Answer:** check the condition, update the instance variable, and return a value on every path.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Consider the following class.

```java
public class Account {
    private int balance;
    public Account(int start) {
        balance = start;
    }
    public void deposit(int amt) {
        balance += amt;
    }
    public void withdraw(int amt) {
        if (amt <= balance) {
            balance -= amt;
        }
    }
    public int getBalance() {
        return balance;
    }
}
```

What is printed by the following code segment?

```java
Account a = new Account(50);
a.withdraw(80);
a.deposit(5);
a.withdraw(55);
System.out.println(a.getBalance());
```

**Answer:** `0`

**Why:** The first withdrawal is refused because 80 is more than 50.

**Working:** Balance: 50; withdraw 80 refused; deposit 5 gives 55; withdraw 55 gives 0.

**Mistakes to avoid**

- `-80`: withdraw only subtracts when there is enough money.
- `55`: The second withdrawal is allowed.
- `-25`: Trace every call, and check each withdrawal against the current balance.

### Worked exam question 2

Consider the following method.

```java
public static void change(int x, int[] arr) {
    x = x + 2;
    arr[0] = arr[0] + 2;
}
```

What is printed by the following code segment?

```java
int n = 17;
int[] nums = {6, 3};
change(n, nums);
System.out.println(n + " " + nums[0]);
```

**Answer:** `17 8`

**Why:** The int is copied, but the array parameter refers to the same array object.

**Working:** Java passes copies of values. For an int, the copy is independent. For an array, the copy is a reference to the same array, so element changes persist.

**Mistakes to avoid**

- `19 8`: x is a copy of n; changing x does not change n.
- `17 6`: arr refers to the same array as nums, so the change to arr[0] is visible.
- `19 6`: Primitives are passed by value; arrays are passed as references to the same object.
