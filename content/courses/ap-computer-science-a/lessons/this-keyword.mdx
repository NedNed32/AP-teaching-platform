Inside an instance method, `this` means "the object this method was called on".

## Resolving shadowing

```java
public class Pet {
    private String name;

    public Pet(String name) {
        this.name = name;   // instance variable = parameter
    }
}
```

Without `this`, `name = name;` would assign the parameter to itself and leave the instance variable null.

## Passing the current object

```java
public boolean isOlderThan(Pet other) {
    return this.age > other.age;
}

public void registerWith(Clinic c) {
    c.add(this);   // pass this object to another method
}
```

A method can access the private instance variables of **another object of the same class**, such as `other.age` above.

<Note title="Implicit this">
When there is no shadowing, `age` and `this.age` mean the same thing in an instance method. `this` is required only when a local name hides the instance variable, or when you need to pass the object itself.
</Note>

<WorkedExample title="Spot the bug">
What does `new Point(3, 4).getX()` return?

```java
public class Point {
    private int x, y;
    public Point(int x, int y) {
        x = x;
        this.y = y;
    }
    public int getX() { return x; }
}
```

1. `x = x;` assigns the parameter to itself; the instance variable `x` is unchanged.
2. It keeps its default value.

**Answer:** `0`.
</WorkedExample>

### Worked exam question 1

Consider the following class.

```java
public class Box {
    private int width;
    private int height;
    public Box(int width, int h) {
        this.width = width;
        height = h;
    }
    public int area() {
        return width * height;
    }
}
```

What is printed by `System.out.println(new Box(5, 8).area());`?

**Answer:** `40`

**Why:** this.width refers to the instance variable, so it is set correctly.

**Working:** this.width = width stores 5 in the instance variable, so the area is 5 × 8 = 40.

**Mistakes to avoid**

- `0`: this.width assigns the instance variable.
- `13`: area multiplies.
- `64`: width is not set from h.
