A `for` loop gathers the initialization, condition and update of a counting loop into one line.

## Structure

```java
for (int i = 1; i <= 5; i++) {
    System.out.print(i + " ");
}
// prints 1 2 3 4 5
```

Order of execution: initialize once; test; run body; update; test; and so on.

## Counting iterations

| Header | Values of i | Iterations |
| --- | --- | --- |
| `i = 0; i < n; i++` | 0 to n − 1 | n |
| `i = 1; i <= n; i++` | 1 to n | n |
| `i = a; i < b; i++` | a to b − 1 | b − a |
| `i = a; i <= b; i++` | a to b | b − a + 1 |

## for and while

Any for loop can be rewritten as a while loop:

```java
int i = 0;
while (i < 10) {
    // body
    i++;
}
```

<Note title="Loop variable scope">
A variable declared in the for header exists only inside the loop. Using `i` after the loop ends is a compile error.
</Note>

<WorkedExample title="Accumulating">
What is printed?

```java
int total = 0;
for (int i = 2; i < 12; i += 3) {
    total += i;
}
System.out.println(total);
```

1. i takes the values 2, 5, 8, 11 (14 fails the test).
2. Total: 2 + 5 + 8 + 11 = 26.

**Answer:** `26`.
</WorkedExample>

### Free-response practice: Letter runs

The class `LetterTools` contains static methods that analyze strings of lowercase letters.

```java
public class LetterTools {
    /** Returns the number of indexes i where the character at i equals the character at i + 1. */
    public static int countDoubles(String s) { /* to be implemented in part (a) */ }
    /** Returns the length of the longest run of identical adjacent characters. */
    public static int longestRun(String s) { /* to be implemented in part (b) */ }
}
```

Examples: `countDoubles("nnnmmmmnm")` returns 5 and `longestRun("nnnmmmmnm")` returns 4; `countDoubles("mnnnmmnm")` returns 3 and `longestRun("mnnnmmnm")` returns 3; `countDoubles("nnmmmmmm")` returns 6 and `longestRun("nnmmmmmm")` returns 6.

**(a)** Write the method `countDoubles`. Assume `s` is not null.

To earn the point: Loops over adjacent pairs without going out of bounds. Model answer: `for (int i = 0; i < s.length() - 1; i++)`

To earn the point: Compares the characters at i and i + 1 correctly (substring with equals, or charAt with ==). Model answer: `s.substring(i, i + 1).equals(s.substring(i + 1, i + 2))`

To earn the point: Counts and returns the number of matching pairs. Model answer:

```java
public static int countDoubles(String s) {
    int count = 0;
    for (int i = 0; i < s.length() - 1; i++) {
        if (s.substring(i, i + 1).equals(s.substring(i + 1, i + 2))) {
            count++;
        }
    }
    return count;
}
```

**(b)** Write the method `longestRun`. Assume `s` has at least one character.

To earn the point: Tracks the length of the current run, extending it when a character matches the previous one. Model answer: cur++ when s.charAt(i) == s.charAt(i - 1)

To earn the point: Resets the current run to 1 when a character differs. Model answer: `cur = 1;`

To earn the point: Keeps and returns the maximum run length, including a run that ends at the last character. Model answer:

```java
public static int longestRun(String s) {
    int best = 1;
    int cur = 1;
    for (int i = 1; i < s.length(); i++) {
        if (s.charAt(i) == s.charAt(i - 1)) {
            cur++;
        } else {
            cur = 1;
        }
        if (cur > best) {
            best = cur;
        }
    }
    return best;
}
```
