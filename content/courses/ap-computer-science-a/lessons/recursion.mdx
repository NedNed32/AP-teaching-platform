A recursive method solves a problem by solving a smaller copy of it. Every recursive method needs a **base case** that stops the recursion.

## A classic example

```java
public static int sumTo(int n) {
    if (n == 0) return 0;          // base case
    return n + sumTo(n - 1);       // recursive call
}
```

`sumTo(3)` = 3 + `sumTo(2)` = 3 + 2 + `sumTo(1)` = 3 + 2 + 1 + `sumTo(0)` = 6.

## Tracing with a stack

Each call waits for the one it made to return. Write the calls going down, then fill in the results coming back up:

| Call | Returns |
| --- | --- |
| `sumTo(3)` | 3 + 3 = 6 |
| `sumTo(2)` | 2 + 1 = 3 |
| `sumTo(1)` | 1 + 0 = 1 |
| `sumTo(0)` | 0 |

## Output before or after the call

```java
public static void show(int n) {
    if (n > 0) {
        show(n - 1);
        System.out.print(n);
    }
}
```

`show(3)` prints `123`, because each print happens **after** the deeper call returns. Moving the print before the call would print `321`.

<Note title="Strings and recursion">
Recursive String methods often use `s.substring(1)` (everything after the first character) to make the problem smaller, with an empty string as the base case.
</Note>

<WorkedExample title="A string recursion">
What does `mystery("abc")` return?

```java
public static String mystery(String s) {
    if (s.length() == 0) return "";
    return mystery(s.substring(1)) + s.substring(0, 1);
}
```

1. mystery("abc") = mystery("bc") + "a".
2. mystery("bc") = mystery("c") + "b" = (mystery("") + "c") + "b" = "cb".

**Answer:** `"cba"`, the reversed string.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Consider the following method.

```java
public static void show(int n) {
    if (n > 0) {
        System.out.print(n % 10);
        show(n / 10);
    }
}
```

What is printed by the call `show(62410)`?

**Answer:** `01426`

**Why:** The last digit prints first, then the recursion handles the rest.

**Working:** Each call prints n % 10 (the last digit) before recursing: 01426.

**Mistakes to avoid**

- `62410`: The print comes before the recursive call.
- `0142`: The recursion continues until n is 0, so every digit prints.
- `014260`: When n is 0, nothing is printed.

### Worked exam question 2

Consider the following method.

```java
public static String mystery(String s) {
    if (s.length() < 2) {
        return s;
    }
    return s.substring(0, 1) + mystery(s.substring(2));
}
```

What is returned by `mystery("trian")`?

**Answer:** `"tin"`

**Why:** Each call keeps the first character and skips the next one.

**Working:** Expanding the calls for "trian" gives "tin".

**Mistakes to avoid**

- `"ra"`: Each call keeps the character at index 0.
- `"trian"`: substring(2) skips a character each time.
- `"ti"`: The base case returns the remaining character.
