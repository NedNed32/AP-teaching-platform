Visiting every cell of a grid takes nested loops. The order of the loops decides the order of the visits.

## Row-major (row by row)

```java
for (int r = 0; r < grid.length; r++) {
    for (int c = 0; c < grid[0].length; c++) {
        System.out.print(grid[r][c] + " ");
    }
    System.out.println();
}
```

## Column-major (column by column)

```java
for (int c = 0; c < grid[0].length; c++) {
    for (int r = 0; r < grid.length; r++) {
        System.out.print(grid[r][c] + " ");
    }
}
```

## Enhanced for loops

```java
int total = 0;
for (int[] row : grid) {
    for (int val : row) {
        total += val;
    }
}
```

<Note title="Bounds come from different places">
Rows: `grid.length`. Columns: `grid[0].length` (or `grid[r].length`). Using the wrong one breaks the loop on any non-square grid.
</Note>

<WorkedExample title="Column-major output">
For `int[][] g = { {1, 2, 3}, {4, 5, 6} };`, what does the column-major loop print?

1. Column 0: 1, 4. Column 1: 2, 5. Column 2: 3, 6.

**Answer:** `1 4 2 5 3 6`.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Consider the following code segment.

```java
int[][] g = {{5, 4, 3}, {9, 8, 5}};
for (int r = 0; r < g.length; r++) {
    for (int c = 0; c < g[0].length; c++) {
        System.out.print(g[r][c] + " ");
    }
}
```

What is printed as a result of executing the code segment?

**Answer:** `5 4 3 9 8 5`

**Why:** The outer loop is over rows: row-major order.

**Working:** The row index is in the outer loop, so the output is 5 4 3 9 8 5.

**Mistakes to avoid**

- `5 9 4 8 3 5`: The outer loop decides the order of the visits.
- `5 8 9 3 4 5`: Both loops count upward.
- `9 8 5 5 4 3`: Row 0 is printed first.

### Free-response practice: Seating chart

A `Theater` stores its seats in a 2D array of student ID numbers. A value of 0 means the seat is empty.

```java
public class Theater {
    private int[][] seats;
    /** Returns the number of empty seats in the given row. */
    public int emptyInRow(int row) { /* part (a) */ }
    /** Returns the index of the first row containing at least k adjacent empty seats,
        or -1 if there is none. */
    public int findBlock(int k) { /* part (b) */ }
}
```

For the chart below, `emptyInRow(3)` returns 5 and `findBlock(2)` returns 0.

```java
 0 20  0  0 67  0  0
 0 63 12  0  0 25 38
59  0  0 94  0 53 81
 0 66  0  0 79  0  0
```

**(a)** Write the method `emptyInRow`.

To earn the point: Traverses every column of the given row. Model answer: `for (int c = 0; c < seats[row].length; c++)`

To earn the point: Counts seats equal to 0 and returns the count. Model answer:

```java
public int emptyInRow(int row) {
    int count = 0;
    for (int c = 0; c < seats[row].length; c++) {
        if (seats[row][c] == 0) {
            count++;
        }
    }
    return count;
}
```

**(b)** Write the method `findBlock`.

To earn the point: Traverses rows in order from 0. Model answer: `for (int r = 0; r < seats.length; r++)`

To earn the point: Tracks the current run of adjacent empty seats, resetting it at an occupied seat and at the start of each row. Model answer: `run = (seats[r][c] == 0) ? run + 1 : 0;`

To earn the point: Returns the row index as soon as a run reaches k. Model answer: `if (run >= k) return r;`

To earn the point: Returns -1 when no row qualifies. Model answer:

```java
public int findBlock(int k) {
    for (int r = 0; r < seats.length; r++) {
        int run = 0;
        for (int c = 0; c < seats[r].length; c++) {
            if (seats[r][c] == 0) {
                run++;
            } else {
                run = 0;
            }
            if (run >= k) {
                return r;
            }
        }
    }
    return -1;
}
```

### Free-response practice: Gradebook

A `Gradebook` stores test scores in a 2D array: each row is a student and each column is a test, in the order the tests were given.

```java
public class Gradebook {
    private int[][] scores;
    /** Returns the average score on test c. */
    public double testAverage(int c) { /* part (a) */ }
    /** Returns the row index of the student whose last score minus first score is greatest.
        If there is a tie, returns the smallest such index. */
    public int mostImproved() { /* part (b) */ }
}
```

For the scores below, `testAverage(1)` returns 69.333 and `mostImproved()` returns 2.

```java
82 87 66 81
61 51 68 55
69 70 96 85
```

**(a)** Write the method `testAverage`.

To earn the point: Traverses every row of column c. Model answer: `for (int r = 0; r < scores.length; r++) sum += scores[r][c];`

To earn the point: Divides by the number of rows without integer division and returns the result. Model answer:

```java
public double testAverage(int c) {
    int sum = 0;
    for (int r = 0; r < scores.length; r++) {
        sum += scores[r][c];
    }
    return (double) sum / scores.length;
}
```

**(b)** Write the method `mostImproved`.

To earn the point: Computes last minus first for each row. Model answer: `scores[r][scores[r].length - 1] - scores[r][0]`

To earn the point: Initializes the best from data (row 0), not from 0. Model answer: `int best = 0; int bestDiff = scores[0][last] - scores[0][0];`

To earn the point: Updates only on a strictly greater difference (keeps the smallest index in a tie) and returns the index. Model answer:

```java
public int mostImproved() {
    int last = scores[0].length - 1;
    int best = 0;
    int bestDiff = scores[0][last] - scores[0][0];
    for (int r = 1; r < scores.length; r++) {
        int diff = scores[r][last] - scores[r][0];
        if (diff > bestDiff) {
            bestDiff = diff;
            best = r;
        }
    }
    return best;
}
```
