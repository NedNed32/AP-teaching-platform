The `Math` class is a library of static methods for common calculations. You call them with the class name, such as `Math.sqrt(16)`.

## Methods on the Java Quick Reference

| Method | Returns |
| --- | --- |
| `Math.abs(int x)` / `Math.abs(double x)` | absolute value (same type) |
| `Math.pow(double base, double exp)` | base raised to exp, as a `double` |
| `Math.sqrt(double x)` | square root, as a `double` |
| `Math.random()` | a `double` in the range 0.0 inclusive to 1.0 exclusive |

## Random integers

To get a random integer from `min` to `max` inclusive:

```java
int range = max - min + 1;
int r = (int) (Math.random() * range) + min;
```

`Math.random() * range` gives a double from 0 up to (not including) `range`; casting truncates to 0 through `range - 1`; adding `min` shifts the range.

<Note title="Mind the types">
`Math.pow` and `Math.sqrt` return `double` even for whole-number inputs. Assigning `Math.sqrt(16)` to an `int` needs a cast: `(int) Math.sqrt(16)`.
</Note>

<WorkedExample title="A random range">
Which values can `(int) (Math.random() * 11) + 5` produce?

1. `Math.random() * 11` is in [0, 11).
2. Casting gives 0 through 10.
3. Adding 5 gives 5 through 15.

**Answer:** every integer from 5 to 15 inclusive.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Consider the following code segment.

```java
int x = (int) (Math.random() * 14) + 3;
```

Which of the following describes all possible values of x?

**Answer:** All integers from 3 to 16, inclusive

**Why:** Math.random() * 14 is in [0, 14); truncating gives 0 to 13, then 3 is added.

**Working:** `(int) (Math.random() * 14)` is an integer from 0 to 13; adding 3 gives 3 to 16.

**Mistakes to avoid**

- All integers from 3 to 17, inclusive: Math.random() never returns 1, so the product is always less than 14.
- All integers from 4 to 17, inclusive: The truncated value can be 0.
- All integers from 0 to 13, inclusive: 3 is added after the cast.

### Worked exam question 2

Which expression produces a random integer from 2 to 9, inclusive?

**Answer:** `(int) (Math.random() * 8) + 2`

**Why:** There are 8 possible values, starting at 2.

**Working:** To get 8 values starting at 2, multiply by 8, cast to int, then add 2.

**Mistakes to avoid**

- `(int) (Math.random() * 7) + 2`: This never produces 9.
- `(int) Math.random() * 8 + 2`: The cast applies to Math.random() alone, which becomes 0, so this is always 2.
- `(int) (Math.random() * 9) + 2`: This can produce values above 9.
