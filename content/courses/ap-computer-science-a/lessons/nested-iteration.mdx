A loop inside a loop processes pairs: every row and column, every pair of items, every pattern line and character.

## How nesting runs

```java
for (int r = 1; r <= 3; r++) {
    for (int c = 1; c <= 4; c++) {
        System.out.print("*");
    }
    System.out.println();
}
```

The inner loop runs **completely** (4 times) for **each** pass of the outer loop (3 times): 12 stars in 3 rows.

## Inner bounds that depend on the outer variable

```java
for (int r = 1; r <= 4; r++) {
    for (int c = 1; c <= r; c++) {
        System.out.print(c);
    }
    System.out.println();
}
```

Output:

```text
1
12
123
1234
```

Total inner passes: $$1 + 2 + 3 + 4 = 10$$.

<Note title="Count with a sum">
When the inner loop's bound changes with the outer variable, add up the inner counts for each outer pass rather than multiplying.
</Note>

<WorkedExample title="Counting inner passes">
How many times is `x++` executed?

```java
int x = 0;
for (int i = 0; i < 5; i++) {
    for (int j = i; j < 5; j++) {
        x++;
    }
}
```

1. For i = 0 to 4, the inner loop runs 5, 4, 3, 2, 1 times.
2. Sum: 15.

**Answer:** 15.
</WorkedExample>
