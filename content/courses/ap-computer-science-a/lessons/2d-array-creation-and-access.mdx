A 2D array models a grid: seats in a theater, pixels in an image, a game board. In Java it is an array whose elements are arrays (rows).

## Creating

```java
int[][] grid = new int[3][4];     // 3 rows, 4 columns, all 0
int[][] m = { {1, 2, 3},
              {4, 5, 6} };        // 2 rows, 3 columns
```

## Accessing

```java
m[1][2]        // row 1, column 2: 6
m.length       // number of rows: 2
m[0].length    // number of columns: 3
m[0][0] = 9;
```

The **first** index is the row, the **second** is the column.

<Note title="Rows are arrays">
`m[1]` is itself an array, the whole second row. That is why `m[0].length` gives the number of columns.
</Note>

<WorkedExample title="Access and update">
Given `int[][] t = { {5, 1, 8}, {2, 7, 3} };`, what is `t[1][0] + t[0][t.length]` after `t[0][2] = t[1][1];`?

1. `t.length` is 2, so `t[0][2]` is used.
2. After the assignment, `t[0][2]` is 7.
3. `t[1][0]` is 2.

**Answer:** 2 + 7 = 9.
</WorkedExample>

### Worked exam question 1

Consider the following code segment.

```java
int[][] m = new int[2][4];
for (int r = 0; r < m.length; r++) {
    for (int c = 0; c < m[0].length; c++) {
        m[r][c] = r * 3 + c;
    }
}
System.out.println(m[1][0] + " " + m.length + " " + m[0].length);
```

What is printed as a result of executing the code segment?

**Answer:** `3 2 4`

**Why:** The first index is the row; m.length is the number of rows.

**Working:** m[1][0] = 1 × 3 + 0 = 3; the array has 2 rows and 4 columns.

**Mistakes to avoid**

- `3 4 2`: m.length counts rows; m[0].length counts columns.
- `1 2 4`: m[1][0] is row 1, column 0.
- `3 8 4`: m.length is the number of rows, not elements.
