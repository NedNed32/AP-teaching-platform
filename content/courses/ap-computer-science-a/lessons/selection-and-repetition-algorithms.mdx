Every algorithm, however complex, is built from three structures: do steps in order, choose between steps, and repeat steps.

## The three building blocks

| Structure | Java construct | Example |
| --- | --- | --- |
| Sequencing | statements in order | compute, then print |
| Selection | `if`, `if-else` | if the score is at least 90, print "A" |
| Repetition | `while`, `for` | add up every value in an array |

## Plan before coding

Write the algorithm in plain steps first:

1. Set `total` to 0.
2. For each number from 1 to `n`: if it is even, add it to `total`.
3. Report `total`.

Then translate each step into Java:

```java
int total = 0;
for (int i = 1; i <= n; i++) {
    if (i % 2 == 0) {
        total += i;
    }
}
System.out.println(total);
```

<Note title="Order matters">
Swapping two statements can change the result. Initializing `total` inside the loop, for example, resets it on every pass.
</Note>

<WorkedExample title="Designing an algorithm">
Describe an algorithm to count how many values in a list exceed 50.

1. Set `count` to 0 (sequencing).
2. Repeat for each value (repetition).
3. If the value is greater than 50, add 1 to `count` (selection).
4. After the loop, return `count`.

**Answer:** the algorithm combines all three building blocks.
</WorkedExample>

## On the practice exams

The practice exams do not ask about this topic on its own, but it supports these questions from the same unit. Work through them to see how the ideas are used.

### Worked exam question 1

Consider the following code segment.

```java
int x = 30;
int count = 0;
while (x > 3) {
    x -= 7;
    count++;
}
System.out.println(count + " " + x);
```

What is printed as a result of executing the code segment?

**Answer:** `4 2`

**Why:** The loop runs 4 times and stops when x is 2.

**Working:** x goes 30, 23, … and the loop ends at x = 2 after 4 passes.

**Mistakes to avoid**

- `3 9`: The loop runs once more: the condition is still true at that point.
- `4 9`: x is decreased inside the loop on the last iteration too.
- `5 -5`: The loop stops as soon as x is no longer greater than the limit.
