These algorithms are the building blocks of the array and ArrayList free-response questions.

## Maximum

```java
int max = arr[0];
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
}
```

## Consecutive pairs

```java
int increases = 0;
for (int i = 0; i < arr.length - 1; i++) {
    if (arr[i + 1] > arr[i]) increases++;
}
```

## Reversing in place

```java
for (int i = 0; i < arr.length / 2; i++) {
    int temp = arr[i];
    arr[i] = arr[arr.length - 1 - i];
    arr[arr.length - 1 - i] = temp;
}
```

## Shifting left by one (rotate)

```java
int first = arr[0];
for (int i = 0; i < arr.length - 1; i++) {
    arr[i] = arr[i + 1];
}
arr[arr.length - 1] = first;
```

<Note title="Start maximums from data">
Starting a maximum at 0 fails when every value is negative. Initialize from the first element instead.
</Note>

<WorkedExample title="Trace a shift">
`int[] a = {5, 8, 2, 6};` After the rotate-left code above, what is `a`?

1. `first = 5`.
2. Shift: [8, 2, 6, 6].
3. Put 5 at the end: [8, 2, 6, 5].

**Answer:** [8, 2, 6, 5].
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Consider the following method.

```java
public static int mystery(int[] arr) {
    int k = 0;
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > arr[k]) {
            k = i;
        }
    }
    return k;
}
```

What is returned by `mystery(new int[] {1, 1, 3, 8, 2, 8})`?

**Answer:** `3`

**Why:** The method returns the index of the first occurrence of the maximum.

**Working:** The maximum 8 occurs at indexes 3 and 5. Using `>`, k ends at 3.

**Mistakes to avoid**

- `5`: With >, a later equal value does not replace k.
- `8`: k stores an index, not a value.
- `4`: Indexes start at 0.

### Worked exam question 2

Consider the following code segment.

```java
int[] a = {5, 3, 9, 6};
int first = a[0];
for (int i = 0; i < a.length - 1; i++) {
    a[i] = a[i + 1];
}
a[a.length - 1] = first;
```

Which of the following represents the contents of `a` after the code segment executes?

**Answer:** `{3, 9, 6, 5}`

**Why:** Every element moves one place left and the first wraps to the end.

**Working:** Tracing the loop on \{5, 3, 9, 6\} gives \{3, 9, 6, 5\}.

**Mistakes to avoid**

- `{6, 5, 3, 9}`: Trace the loop direction and indexes carefully.
- `{5, 5, 5, 5}`: Trace the loop direction and indexes carefully.
- `{6, 9, 3, 5}`: Shifting is not reversing.

### Worked exam question 3

Consider the following code segment.

```java
int[] a = {4, 9, 3, 2, 1, 5};
for (int i = 0; i < a.length / 2; i++) {
    a[a.length - 1 - i] = a[i];
}
```

Which of the following represents the contents of `a` after the code segment executes?

**Answer:** `{4, 9, 3, 3, 9, 4}`

**Why:** The back half is overwritten with a copy of the front half, so the array reads the same both ways.

**Working:** Each a[i] in the front half is copied to its mirror position, giving \{4, 9, 3, 3, 9, 4\}.

**Mistakes to avoid**

- `{5, 1, 2, 3, 9, 4}`: Reversing needs a swap with a temporary variable; this only copies.
- `{5, 1, 2, 2, 1, 5}`: Values are copied from index i to the back, not the other way.
- `{4, 9, 3, 2, 1, 5}`: The loop assigns to the back half.
