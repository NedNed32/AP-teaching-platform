Two programs can solve the same problem with very different amounts of work. The AP exam measures work informally by counting how many times a statement executes.

## Counting executions

| Code shape | Executions of the inner statement |
| --- | --- |
| one loop, n passes | $$n$$ |
| loop with `i += 2` | about $$\frac[n][2]$$ |
| two nested loops, n each | $$n^2$$ |
| inner loop runs i times, i = 1 to n | $$\frac[n(n + 1)][2]$$ |
| loop that halves n each pass | about $$\log_2 n$$ |

## Why it matters

For large inputs the growth rate dominates. An algorithm with $$n^2$$ steps on a million items does a trillion operations, while one with $$n$$ steps does a million.

<Note title="Count precisely when asked">
Multiple-choice questions often ask for the exact number of times a line runs for a specific input. Trace the loop bounds carefully, including the last value where the condition fails.
</Note>

<WorkedExample title="Exact count">
How many times does `sum += k;` execute when n = 10?

```java
for (int k = 1; k < n; k *= 2) {
    sum += k;
}
```

1. k takes the values 1, 2, 4, 8; 16 fails the test.

**Answer:** 4 times.
</WorkedExample>

## On the practice exams

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** Consider the following code segment. ```java int count = 0; for (int i = 1; i <= 12; i++) { for (int j = 1; j < i; j++) { count++; } } ``` How many times is `count++` executed?

**A.** `66`. Add the inner-loop executions for each value of i. Summing the inner loop's executions over i = 1 to 12 gives 66.
