Instance methods operate on a specific object. You call them with **dot notation**: the object reference, a dot, then the method.

## Calling instance methods

```java
BankAccount acct = new BankAccount(100.0);
acct.deposit(50.0);                 // void mutator: a statement
double b = acct.getBalance();       // accessor: use the returned value
```

## Void versus non-void

| Kind | Returns | How to call |
| --- | --- | --- |
| `void` | nothing | as its own statement |
| non-void | a value | in an expression, assignment or print |

`double x = acct.deposit(5.0);` does not compile if `deposit` is `void`.

<Note title="Each object has its own state">
`a.deposit(10)` changes only the object `a` refers to. Another account object is unaffected (unless it is an alias of `a`).
</Note>

<WorkedExample title="Tracing method calls">
A `Thermostat` starts at 68. `raise(int d)` adds d; `getTemp()` returns the temperature. What is printed?

```java
Thermostat t = new Thermostat();
t.raise(4);
t.raise(t.getTemp() / 24);
System.out.println(t.getTemp());
```

1. After `raise(4)`: 72.
2. `72 / 24` is 3, so `raise(3)`: 75.

**Answer:** `75`.
</WorkedExample>

### Worked exam question 1

Consider the following code segment.

```java
String s = "painting";
int i = s.indexOf("a");
System.out.println(s.substring(i + 1) + i);
```

What is printed as a result of executing the code segment?

**Answer:** `inting1`

**Why:** indexOf returns the first position of "a", which is 1.

**Working:** "a" first appears at index 1, so the substring from 2 is "inting" and 1 is appended.

**Mistakes to avoid**

- `nting2`: indexOf counts from 0.
- `ainting1`: substring(i + 1) starts after the found letter.
- `inting2`: i itself is printed, not i + 1.
