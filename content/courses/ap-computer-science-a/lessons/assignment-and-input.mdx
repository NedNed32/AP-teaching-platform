The `=` sign in Java is not a statement of equality; it is an instruction: compute the value on the right, then store it in the variable on the left.

## Tracing assignments

Keep a small table of variable values and update it one line at a time:

```java
int a = 5;
int b = a * 2;   // b = 10
a = b - a;       // a = 5
b = a + b;       // b = 15
```

| after line | a | b |
| --- | --- | --- |
| 1 | 5 | |
| 2 | 5 | 10 |
| 3 | 5 | 10 |
| 4 | 5 | 15 |

## Reading input

```java
import java.util.Scanner;

Scanner input = new Scanner(System.in);
int age = input.nextInt();
String name = input.nextLine();
```

<Note title="Swapping needs a temporary variable">
`a = b; b = a;` does not swap: after the first line both hold the old value of `b`. Save one value first in a temporary variable.
</Note>

<WorkedExample title="A trace">
What are the final values of x and y?

```java
int x = 4;
int y = 9;
x = x + y;
y = x - y;
x = x - y;
```

1. `x = 13`.
2. `y = 13 - 9 = 4`.
3. `x = 13 - 4 = 9`.

**Answer:** x is 9 and y is 4: the values were swapped without a temporary variable.
</WorkedExample>

## On the practice exams

The practice exams do not ask about this topic on its own, but it supports these questions from the same unit. Work through them to see how the ideas are used.

### Worked exam question 1

Consider the following code segment.

```java
int a = 39;
int b = 4;
System.out.println(a / b + a % b);
```

What is printed as a result of executing the code segment?

**Answer:** `12`

**Why:** 39 / 4 is 9 (integer division) and 39 % 4 is 3.

**Working:** With two int operands, `/` gives the truncated quotient 9 and `%` gives the remainder 3, so the sum is 12.

**Mistakes to avoid**

- `93`: The + is between two ints, so it adds; it does not concatenate.
- `13`: Integer division truncates; it does not round.
- `9`: The remainder is added as well.

### Worked exam question 2

Consider the following code segment.

```java
int total = 47;
int count = 5;
double avg1 = total / count;
double avg2 = (double) total / count;
System.out.println(avg1 + " " + avg2);
```

What is printed as a result of executing the code segment?

**Answer:** `9.0 9.4`

**Why:** avg1 divides two ints before converting; avg2 casts first.

**Working:** `total / count` is integer division (9), then widened to 9.0. `(double) total / count` casts first, giving 9.4.

**Mistakes to avoid**

- `9.4 9.4`: In avg1 the division happens between two ints, so the decimal part is lost before the result is stored.
- `9.0 9.0`: The cast in avg2 applies to total before dividing, so the division is done with doubles.
- `9 9.4`: avg1 is a double, so it prints with a decimal point.

### Worked exam question 3

Consider the following code segment.

```java
int x = 8;
x *= 3;
x /= 4;
x -= 7;
x += 4;
System.out.println(x);
```

What is printed as a result of executing the code segment?

**Answer:** `3`

**Why:** Apply each statement in order, using integer division.

**Working:** Starting from 8, the statements give 24, 6, -1, 3.

**Mistakes to avoid**

- `-1`: Every statement runs, including the last one.
- `-3`: /= keeps the quotient and %= keeps the remainder.
- `4`: Recheck each step.
