Informally, a continuous function is one whose graph has no breaks. To *justify* continuity on the AP exam you need the precise version, which turns that picture into three checks.

## The definition

A function $$f$$ is **continuous at $$x = c$$** if all three hold:

1. $$f(c)$$ is defined.
2. $$\lim_{x \to c} f(x)$$ exists (both one-sided limits exist and agree).
3. $$\lim_{x \to c} f(x) = f(c)$$.

Condition 3 is the heart of it: the value of the function is exactly what the nearby values predict.

## How each type of discontinuity fails

| Discontinuity | Condition that fails |
| --- | --- |
| Hole, $$f(c)$$ undefined | 1 |
| Jump | 2 |
| Hole with a misplaced dot | 3 |
| Vertical asymptote | 2 (and often 1) |

<Note title="Writing the justification">
A full-credit justification computes the left-hand limit, the right-hand limit and the function value, then states that they are all equal (or which ones are not). Saying the graph has no break is not enough.
</Note>

<WorkedExample title="Checking a piecewise function">
Let $$f(x) = x^2 + 1$$ for $$x \leq 2$$ and $$f(x) = 3x - 1$$ for $$x > 2$$. Is $$f$$ continuous at $$x = 2$$?

1. $$f(2) = 2^2 + 1 = 5$$, so $$f(2)$$ is defined.
2. $$\lim_{x \to 2^-} f(x) = 5$$ and $$\lim_{x \to 2^+} f(x) = 3(2) - 1 = 5$$, so the limit exists and equals 5.
3. $$\lim_{x \to 2} f(x) = 5 = f(2)$$.

**Answer:** yes, $$f$$ is continuous at $$x = 2$$.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Let $$f(x) = \begin{cases} kx - 3 & x < -1 \\ x^{2} + 1 & x \geq -1 \end{cases}$$ where $$k$$ is a constant. For what value of $$k$$ is $$f$$ continuous at $$x = -1$$?

**Answer:** $$-5$$

**Why:** Continuity needs $$k(-1) - 3 = (-1)^2 + 1$$, which gives $$k = -5$$.

**Working:** $$f$$ is continuous at $$-1$$ when the left-hand limit equals $$f(-1) = 2$$. The left-hand limit is $$-1k - 3$$, so $$-1k - 3 = 2$$ and $$k = -5$$.

**Mistakes to avoid**

- $$1$$: This comes from a sign error when moving the constant term across the equation.
- $$-2$$: This matches the slopes of the two pieces, which is the condition for differentiability, not continuity.
- $$5$$: This forgets to divide by $$-1$$ when solving for $$k$$.
