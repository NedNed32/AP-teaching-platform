Calculus lets you sketch a graph from its derivatives: $$f'$$ says where the graph rises and falls, $$f''$$ says how it bends. Going the other way, you can sketch $$f'$$ just by reading slopes off $$f$$.

## From f prime and f double prime to f

1. Find where $$f' > 0$$ (rising) and $$f' < 0$$ (falling).
2. Mark relative extrema where $$f'$$ changes sign.
3. Find where $$f'' > 0$$ (concave up) and $$f'' < 0$$ (concave down).
4. Mark inflection points.
5. Plot key points and asymptotes, then connect with the right shape on each interval.

## From f to f prime

| Feature of $$f$$ | Feature of $$f'$$ |
| --- | --- |
| increasing | above the x-axis |
| horizontal tangent | zero (crosses or touches the axis) |
| concave up | increasing |
| inflection point | relative max or min |
| corner or cusp | undefined (a gap or jump) |

<Note title="Four shapes on any interval">
Each interval between key points has one of four shapes: increasing and concave up, increasing and concave down, decreasing and concave up, decreasing and concave down. Name the shape for each interval before drawing.
</Note>

<WorkedExample title="Reading the figure">
Use the figure, where $$f'(x) = x^2 - x - 2$$.

1. $$f' = (x - 2)(x + 1)$$ is positive for $$x < -1$$, negative on $$(-1, 2)$$, positive for $$x > 2$$.
2. So $$f$$ rises, falls, then rises: relative maximum at $$x = -1$$, relative minimum at $$x = 2$$.
3. $$f'' = 2x - 1$$ changes sign at $$x = \frac{1}{2}$$, where $$f'$$ has its minimum.

**Answer:** the graph of $$f$$ peaks at $$x = -1$$, bottoms out at $$x = 2$$, and changes from concave down to concave up at $$x = \frac{1}{2}$$.
</WorkedExample>

**Q.** On which of the following intervals is the graph of $$f$$ concave down?

**A.** $$(1, 2)$$. $$f'$$ is decreasing there, so $$f'' < 0$$. $$f$$ is concave down where $$f'$$ is decreasing, which on this graph means a segment sloping downward.

**Q.** On the open interval $$0 < x < 6$$, at how many values of $$x$$ does $$f$$ have a relative maximum?

**A.** $$1$$. Count the places where f′ crosses the x-axis from above to below. $$f$$ has a relative maximum where $$f'$$ changes from positive to negative. On this graph that happens 1 time.
