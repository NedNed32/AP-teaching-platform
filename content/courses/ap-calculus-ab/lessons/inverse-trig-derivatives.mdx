Inverse trig functions return angles. Their derivatives, surprisingly, are algebraic: no trig functions remain.

## The formulas

$$
\frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1 - x^2}} \qquad \frac{d}{dx}\arccos x = -\frac{1}{\sqrt{1 - x^2}} \qquad \frac{d}{dx}\arctan x = \frac{1}{1 + x^2}
$$

The AP exam focuses on arcsine and arctangent; arccosine is the negative of arcsine.

## Where arctangent comes from

Let $$y = \arctan x$$, so $$\tan y = x$$. Implicit differentiation gives $$\sec^2 y \cdot y' = 1$$, so $$y' = \frac{1}{\sec^2 y} = \frac{1}{1 + \tan^2 y} = \frac{1}{1 + x^2}$$.

## With the chain rule

$$
\frac{d}{dx}\arcsin(u) = \frac{u'}{\sqrt{1 - u^2}} \qquad \frac{d}{dx}\arctan(u) = \frac{u'}{1 + u^2}
$$

<Note title="Square the whole inside">
For $$\arctan(5x)$$, the denominator is $$1 + (5x)^2 = 1 + 25x^2$$, not $$1 + 5x^2$$. And do not forget the factor 5 on top.
</Note>

<WorkedExample title="Arcsine with a scaled input">
Find $$f'(2)$$ for $$f(x) = \arcsin\left(\frac{x}{4}\right)$$.

1. $$u = \frac{x}{4}$$, $$u' = \frac{1}{4}$$.
2. $$f'(x) = \frac{1/4}{\sqrt{1 - x^2/16}} = \frac{1}{\sqrt{16 - x^2}}$$.
3. $$f'(2) = \frac{1}{\sqrt{12}}$$.

**Answer:** $$\frac{1}{2\sqrt{3}}$$.
</WorkedExample>

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** If $$f(x) = \arcsin\left(\frac{x}{2}\right)$$, what is $$f'(1)$$?

**A.** $$\frac{1}{\sqrt{3}}$$. $$f'(x) = \frac{1}{\sqrt{1 - x^2/4}} \cdot \frac{1}{2} = \frac{1}{\sqrt{4 - x^2}}$$. $$\frac{d}{dx}\arcsin u = \frac{u'}{\sqrt{1 - u^2}}$$. With $$u = \frac{x}{2}$$, $$f'(1) = \frac{1/2}{\sqrt{3/4}} = \frac{1}{\sqrt{3}}$$.

**Q.** If $$f(x) = \arcsin\left(\frac{x}{13}\right)$$, what is $$f'(5)$$?

**A.** $$\frac{1}{12}$$. $$f'(x) = \frac{1}{\sqrt{169 - x^2}}$$, so $$f'(5) = \frac{1}{\sqrt{144}} = \frac{1}{12}$$. $$\frac{d}{dx}\arcsin\left(\frac{x}{13}\right) = \frac{1/13}{\sqrt{1 - x^2/169}} = \frac{1}{\sqrt{169 - x^2}}$$. At $$x = 5$$ this is $$\frac{1}{12}$$.

**Q.** If $$f(x) = \arctan(2x)$$, what is $$f'(2)$$?
