When a formula is awkward or you only have data, you can estimate a limit by evaluating the function closer and closer to the target input and watching the outputs.

## Building a table

Take $$f(x) = \frac{\sin x}{x}$$, which is undefined at 0. Choose inputs that approach 0 from each side:

| $$x$$ | $$-0.1$$ | $$-0.01$$ | $$-0.001$$ | $$0.001$$ | $$0.01$$ | $$0.1$$ |
| --- | --- | --- | --- | --- | --- | --- |
| $$f(x)$$ | 0.99833 | 0.99998 | 0.9999998 | 0.9999998 | 0.99998 | 0.99833 |

Both sides close in on 1, so we estimate $$\lim_{x \to 0} \frac{\sin x}{x} = 1$$. (This limit is proved with the Squeeze Theorem in topic 1.8.)

## Reading a table well

- **Read from the outside in.** The rows nearest the target matter most.
- **Compare the two sides.** If the left values approach one number and the right values another, the two-sided limit does not exist.
- **Watch for growth without bound.** Outputs such as 100, 10 000, 1 000 000 suggest an infinite limit (topic 1.14).
- **Watch for oscillation.** Values that keep jumping around do not settle, so there is no limit.

<Note title="A table is evidence, not proof">
A table can be fooled by a function that changes behavior very close to the point. On the AP exam, a table-based estimate is accepted when the question asks for one, but justifications that need certainty use algebra or a theorem.
</Note>

<WorkedExample title="One-sided limits from data">
A function $$g$$ has these values:

| $$x$$ | 1.9 | 1.99 | 1.999 | 2.001 | 2.01 | 2.1 |
| --- | --- | --- | --- | --- | --- | --- |
| $$g(x)$$ | 4.8 | 4.98 | 4.998 | 7.002 | 7.02 | 7.2 |

1. From the left the outputs approach 5, so $$\lim_{x \to 2^-} g(x) \approx 5$$.
2. From the right they approach 7, so $$\lim_{x \to 2^+} g(x) \approx 7$$.

**Answer:** the one-sided limits differ, so $$\lim_{x \to 2} g(x)$$ does not exist.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

The function $$f$$ is defined for all real numbers except $$x = 4$$. Selected values of $$f$$ are shown.

*Values of f near x = 4*

| $$x$$ | $$f(x)$$ |
| --- | --- |
| 3.9 | -0.1 |
| 3.99 | -0.01 |
| 3.999 | -0.001 |
| 4.001 | 2.001 |
| 4.01 | 2.01 |
| 4.1 | 2.1 |

Based on the table, which of the following is the best estimate of $$\lim_{x \to 4} f(x)$$?

**Answer:** The limit does not exist.

**Why:** From the left the outputs approach 0; from the right they approach 2. The one-sided limits differ.

**Working:** Read the table toward $$x = 4$$ from each side. The left side approaches 0 and the right side approaches 2, so the two-sided limit does not exist.

**Mistakes to avoid**

- $$0$$: This is only the left-hand trend.
- $$2$$: This is only the right-hand trend.
- $$1$$: Averaging the two sides is never how a limit is found.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** The function $$g$$ is defined by $$g(x) = \frac{\sin(5x)}{e^{6x} - 1}$$ for $$x \neq 0$$. For what value of $$g(0)$$ is $$g$$ continuous at $$x = 0$$?

**A.** $$0.833$$. Evaluating $$g$$ at inputs very close to 0 (or using the limits of $$\frac{\sin u}{u}$$ and $$\frac{e^u - 1}{u}$$) gives $$\frac{5}{6}$$. For continuity, $$g(0)$$ must equal $$\lim_{x \to 0} g(x)$$. Near 0, $$\sin(5x) \approx 5x$$ and $$e^{6x} - 1 \approx 6x$$, so the limit is $$\frac{5}{6} \approx 0.833$$. A table of values near 0 confirms it.
