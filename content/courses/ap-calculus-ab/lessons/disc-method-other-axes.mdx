The axis of revolution does not have to be a coordinate axis. Revolving around $$y = 3$$ or $$x = -2$$ works the same way; only the radius changes.

## The radius is a distance

For a horizontal axis $$y = k$$, the radius from the axis to the curve $$y = f(x)$$ is

$$
R(x) = |f(x) - k|,
$$

usually written as (larger $$y$$) minus (smaller $$y$$). For a vertical axis $$x = h$$, the radius to the curve $$x = g(y)$$ is (larger $$x$$) minus (smaller $$x$$).

## The method

1. Sketch the region and the axis.
2. Confirm the region touches the axis (otherwise use washers).
3. Write the radius as a distance.
4. $$V = \pi\int R^2$$, integrating along the axis direction.

<Note title="Check with a test point">
Plug in one value of $$x$$ and make sure your radius gives a positive distance that matches the sketch. A sign error here squares away and gives a believable but wrong answer.
</Note>

<WorkedExample title="Revolving about the top boundary">
The region bounded by $$y = x^2$$ and $$y = 1$$ is revolved about the line $$y = 1$$. Find the volume.

1. The region runs from $$x = -1$$ to $$x = 1$$ and touches $$y = 1$$, so discs apply.
2. Radius: $$R(x) = 1 - x^2$$.
3. $$V = \pi\int_{-1}^{1} (1 - x^2)^2\,dx = 2\pi\int_0^1 (1 - 2x^2 + x^4)\,dx = 2\pi\left(1 - \frac{2}{3} + \frac{1}{5}\right)$$.

**Answer:** $$\frac{16\pi}{15} \approx 3.351$$.
</WorkedExample>

**Q.** Let $$R$$ be the region enclosed by $$y = x$$ and $$y = x^2$$. Which of the following gives the volume of the solid generated when $$R$$ is revolved about the line $$y = -1$$?

**A.** $$\pi\int_0^1 \left[(x + 1)^2 - (x^2 + 1)^2\right]dx$$. The radii are measured from $$y = -1$$: outer $$x + 1$$, inner $$x^2 + 1$$. Washers: $$V = \pi\int_0^1 \left[R(x)^2 - r(x)^2\right]dx$$ with $$R = x - (-1)$$ and $$r = x^2 - (-1)$$.

**Q.** Let $$R$$ be the region bounded by $$y = x^2$$ and $$y = 4$$. Which of the following gives the volume of the solid generated when $$R$$ is revolved about the line $$y = 4$$?

**A.** $$\pi\int_{-2}^{2} (4 - x^2)^2\,dx$$. Each disc has radius $$4 - x^2$$, the distance from the curve to the axis. Revolving about $$y = 4$$, which is the top boundary, gives discs of radius $$4 - x^2$$.
