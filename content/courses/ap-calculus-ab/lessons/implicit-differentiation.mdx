The circle $$x^2 + y^2 = 25$$ is not the graph of a single function, yet it clearly has a slope at most points. Implicit differentiation finds that slope without solving for $$y$$.

## The method

1. Differentiate **both sides** of the equation with respect to $$x$$.
2. Every time you differentiate a term containing $$y$$, multiply by $$\frac{dy}{dx}$$ (chain rule), because $$y$$ depends on $$x$$.
3. Collect the $$\frac{dy}{dx}$$ terms on one side and factor.
4. Solve for $$\frac{dy}{dx}$$.

For the circle: $$2x + 2y\frac{dy}{dx} = 0$$, so $$\frac{dy}{dx} = -\frac{x}{y}$$.

The answer usually contains both $$x$$ and $$y$$. To get a number, substitute **both coordinates** of a point on the curve.

## Typical terms

| Term | Derivative with respect to $$x$$ |
| --- | --- |
| $$y^2$$ | $$2y\,y'$$ |
| $$xy$$ | $$y + x\,y'$$ |
| $$\sin y$$ | $$\cos y \cdot y'$$ |
| $$e^{y}$$ | $$e^{y}\,y'$$ |

<Note title="The product rule hides in xy">
Forgetting the product rule on terms like $$xy$$ or $$x^2y^3$$ is the most common implicit-differentiation error. Each such term produces two pieces.
</Note>

<WorkedExample title="Slope on a tilted ellipse">
Find the slope of $$x^2 + xy + y^2 = 7$$ at $$(1, 2)$$.

1. Differentiate: $$2x + (y + xy') + 2yy' = 0$$.
2. Collect: $$y'(x + 2y) = -(2x + y)$$, so $$y' = -\frac{2x + y}{x + 2y}$$.
3. At $$(1, 2)$$: $$-\frac{2 + 2}{1 + 4}$$.

**Answer:** the slope is $$-\frac{4}{5}$$.
</WorkedExample>

**Q.** What is the slope of the line tangent to the curve $$x^2 + y^2 = 169$$ at the point $$(-12, 5)$$?

**A.** $$\frac{12}{5}$$. $$2x + 2y\frac{dy}{dx} = 0$$ gives $$\frac{dy}{dx} = -\frac{x}{y} = -\frac{-12}{5}$$. Differentiate implicitly: $$2x + 2y\,y' = 0$$, so $$y' = -\frac{x}{y}$$. At $$(-12, 5)$$ this is $$\frac{12}{5}$$.

### Free-response practice: An implicitly defined curve

Consider the curve given by $$x^2 - xy + y^2 = 3$$.

**(a)** Show that $$\frac{dy}{dx} = -\frac{2x - y}{-x + 2y}$$.

To earn the point: Differentiates implicitly, using the product rule on the $$xy$$ term. Model answer: $$2x - \left(y + x\frac{dy}{dx}\right) + 2y\frac{dy}{dx} = 0$$

To earn the point: Solves for $$\frac{dy}{dx}$$ to reach the given expression. Model answer: $$\frac{dy}{dx}(-x + 2y) = -(2x - y)$$

**(b)** Write an equation for the line tangent to the curve at the point $$(-1, 1)$$.

To earn the point: Finds the slope and writes the line. Model answer: $$\frac{dy}{dx} = 1$$, so $$y - 1 = 1(x + 1)$$

**(c)** Find the coordinates of every point on the curve at which the tangent line is horizontal.

To earn the point: Sets the numerator equal to zero. Model answer: $$2x - y = 0$$, so $$y = 2x$$

To earn the point: Substitutes into the curve and solves. Model answer: $$3x^2 = 3$$, so $$x = \pm 1$$
