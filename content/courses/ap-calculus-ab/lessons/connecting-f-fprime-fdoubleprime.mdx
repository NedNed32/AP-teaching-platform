The AP exam's favorite graph is often not $$f$$ but $$f'$$. Being fluent in moving between the three levels, function, slope and bending, is one of the most valuable skills in the course.

## The master table

| If you know | Then $$f$$ is |
| --- | --- |
| $$f' > 0$$ | increasing |
| $$f' < 0$$ | decreasing |
| $$f'$$ changes $$+$$ to $$-$$ | at a relative maximum |
| $$f'$$ changes $$-$$ to $$+$$ | at a relative minimum |
| $$f'$$ increasing, or $$f'' > 0$$ | concave up |
| $$f'$$ decreasing, or $$f'' < 0$$ | concave down |
| $$f'$$ has a relative extremum, or $$f''$$ changes sign | at an inflection point |

## Given the graph of f prime

Two different readings of the same graph:

- **Height** of $$f'$$ (above or below the axis) tells you about the **direction** of $$f$$.
- **Slope** of $$f'$$ (rising or falling) tells you about the **concavity** of $$f$$.

Mixing these two up is the most common error on graph-of-the-derivative questions.

<Note title="Tables of signs">
Some questions give a table with the signs of $$f'$$ and $$f''$$ on intervals. Treat each row as one of the four shapes (rising or falling, cup or cap) and sketch accordingly.
</Note>

<WorkedExample title="Reading f prime from data">
A differentiable $$f$$ has $$f'(x) = (x - 1)^2(x - 4)$$. Find the relative extrema and inflection points of $$f$$.

1. $$f'$$ changes sign only at $$x = 4$$ (from negative to positive), so $$f$$ has a relative minimum at $$x = 4$$; at $$x = 1$$ it does not change sign, so there is no extremum there.
2. $$f''(x) = 2(x - 1)(x - 4) + (x - 1)^2 = (x - 1)(3x - 9) = 3(x - 1)(x - 3)$$.
3. $$f''$$ changes sign at $$x = 1$$ and $$x = 3$$.

**Answer:** relative minimum at $$x = 4$$; inflection points at $$x = 1$$ and $$x = 3$$.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

At what value of $$x$$ does the graph of $$f(x) = x^{3} - 9x^{2} + 2x - 4$$ have a point of inflection?

**Answer:** $$3$$

**Why:** $$f''(x) = 6x - 18$$ is zero and changes sign at $$x = 3$$.

**Working:** $$f'(x) = 3x^{2} - 18x + 2$$ and $$f''(x) = 6x - 18$$. $$f''$$ is linear, so it changes sign at its zero, $$x = 3$$.

**Mistakes to avoid**

- $$-3$$: Sign error when solving f″(x) = 0.
- $$\frac{9}{2}$$: This is −b/(2a), the vertex formula for a parabola, applied to the cubic's coefficients. Set f″(x) = 0 instead.
- $$0$$: Inflection points are where f″ changes sign, not where f″ has its constant term.

**Q.** On which of the following intervals is the graph of $$f$$ concave down?

**A.** $$(1, 2)$$. $$f'$$ is decreasing there, so $$f'' < 0$$. $$f$$ is concave down where $$f'$$ is decreasing, which on this graph means a segment sloping downward.
