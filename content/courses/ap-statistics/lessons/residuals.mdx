$$\text{residual} = y - \hat y$$

- Positive residual: the actual value is **above** the line (underprediction).
- Negative: **below** the line (overprediction).

A good linear model has a residual plot with **no pattern**, scattered randomly around 0. A curve means a nonlinear model may fit better; a fan shape means variability changes with x.

<Note title="Residuals sum to zero">
For the least-squares line, the residuals always add to 0.
</Note>

<WorkedExample title="Compute">
ŷ = 20 + 3x. A point has x = 5 and y = 31. Find and interpret the residual.

1. $$\hat y = 35$$; residual = $$31 - 35 = -4$$.

**Answer:** −4: the actual value is 4 units below what the model predicts.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

The regression line is ŷ = 33 − 3x. An observation has x = 12 and y = 2.6. What is its residual, and what does it mean?

**Answer:** 5.6; the actual value is above the predicted value

**Why:** Residual = y − ŷ.

**Working:** ŷ = -3; residual = 2.6 − -3 = 5.6.

**Mistakes to avoid**

- -5.6; the actual value is below the predicted value: Residual = actual − predicted, not predicted − actual.
- -3; this is the residual: That is the predicted value ŷ.
- 5.6; the actual value is below the predicted value: A positive residual means the point is above the line.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** A point with an x value far from the others noticeably changes the slope when removed. What is it?

**A.** An influential point. Removing it changes the regression line substantially.

**Q.** A residual plot shows a clear curved pattern. What does this indicate?

**A.** A linear model is not appropriate for the data. Curvature in residuals means the relationship is not linear.

**Q.** A regression of weight (kg) on height (cm) for children aged 5–10 is used to predict the weight of an adult who is 180 cm tall. What is the main problem?

**A.** Extrapolation beyond the range of the data. The pattern may not hold for adults.

**Q.** Which statement about the correlation r is true?

**A.** r does not change if the units of x or y change. r has no units.

**Q.** The slope of a regression line predicting exam score from hours studied is 3.5. Which interpretation is correct?

**A.** For each additional hour studied, the predicted exam score increases by about 3.5 points. Slope is the predicted change in y per unit of x.

### Free-response practice: Predicting exam score

Data were collected on hours studied per week (x) and exam score (y) for a sample of students. A scatterplot shows a linear pattern, and the residual plot shows no pattern. Computer output for the least-squares regression is shown.

```text
Predictor   Coef      SE Coef
Constant    27.8
x           3
S = 3.9    R-Sq = 86.0%
```

**(a)** Write the equation of the least-squares regression line, defining the variables.

To earn the point: Correct equation with variables defined. Model answer: ŷ = 27.8 + 3x, where ŷ is predicted exam score and x is hours studied per week.

**(b)** Interpret the slope and the value of R-Sq in context.

To earn the point: Slope interpretation. Model answer: For each additional unit of hours studied per week, the predicted exam score increases by about 3.

To earn the point: R-Sq interpretation. Model answer: About 86.0% of the variation in exam score is accounted for by the linear model with hours studied per week.

**(c)** One observation has x = 4 and y = 36.3. Calculate and interpret its residual. Also find the correlation r.

To earn the point: Residual and interpretation. Model answer: ŷ = 39.8; residual = 36.3 − 39.8 = -3.5: the actual value is below the prediction.

To earn the point: Correlation with the correct sign. Model answer: r = √0.86 = 0.927

**(d)** The data come from a convenience sample. Explain how this affects the conclusions and describe a better data collection method.

To earn the point: Results may not generalize to the population; a random sample would allow generalization. Model answer: Take a simple random sample of students from the population of interest. Observational data also cannot show causation.
