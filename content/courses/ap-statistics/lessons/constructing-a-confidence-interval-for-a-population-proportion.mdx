$$\hat p \pm z^*\sqrt{\frac{\hat p(1-\hat p)}{n}}$$

| Confidence | z* |
| --- | --- |
| 90% | 1.645 |
| 95% | 1.960 |
| 99% | 2.576 |

## Four steps

1. **State** the parameter and confidence level.
2. **Plan**: name the procedure (one-sample z interval for p) and check conditions (random, 10%, large counts with $$n\hat p$$ and $$n(1-\hat p)$$).
3. **Do** the calculation.
4. **Conclude** in context.

The margin of error shrinks with larger n and lower confidence.

<Note title="Sample size for a margin">
To get margin of error m, solve n ≥ (z*/m)² p̂(1 − p̂); use p̂ = 0.5 if no estimate is available.
</Note>

<WorkedExample title="Construct">
In a random sample of 500 teens, 310 say they read for fun weekly. Construct a 95% confidence interval for p.

1. $$\hat p = 0.62$$; SE = $$\sqrt{0.62(0.38)/500} = 0.0217$$.
2. $$0.62 \pm 1.96(0.0217) = 0.62 \pm 0.0425$$.

**Answer:** (0.577, 0.663).
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

In a random sample of 210 adults in a city, 82 use public transit weekly. Which is a 95% confidence interval for the proportion of all adults in a city who use public transit weekly?

**Answer:** (0.324, 0.456)

**Why:** p̂ ± z*√(p̂(1 − p̂)/n) with z* = 1.96.

**Working:** p̂ = 0.39, SE = 0.0337, margin = 0.066.

**Mistakes to avoid**

- (0.139, 0.642): Divide by n inside the square root.
- (-0.076, 0.857): Use the standard error, √(p̂(1 − p̂)/n).
- (0.357, 0.424): Multiply the standard error by z*.
