Concavity of a parametric curve is still governed by $$\frac{d^2y}{dx^2}$$, but there is a trap: you cannot simply divide $$y''(t)$$ by $$x''(t)$$.

## The formula

$$\frac{dy}{dx}$$ is itself a function of $$t$$. To differentiate it with respect to $$x$$, use the same parametric rule again:

$$
\frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right) = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{\frac{dx}{dt}}.
$$

## Steps

1. Find $$\frac{dy}{dx} = \frac{y'(t)}{x'(t)}$$ and simplify.
2. Differentiate that expression with respect to $$t$$.
3. Divide by $$x'(t)$$.
4. Positive means concave up; negative means concave down.

<Note title="Simplify first">
Simplifying $$\frac{dy}{dx}$$ before differentiating (for instance $$\frac{3t^2}{2t} = \frac{3t}{2}$$) makes step 2 much easier and avoids a quotient rule.
</Note>

<WorkedExample title="Concavity on a curve">
For $$x = t + 1$$, $$y = t^3 - 3t$$, where is the curve concave up?

1. $$\frac{dy}{dx} = \frac{3t^2 - 3}{1} = 3t^2 - 3$$.
2. $$\frac{d}{dt}(3t^2 - 3) = 6t$$.
3. $$\frac{d^2y}{dx^2} = \frac{6t}{1} = 6t$$.

**Answer:** concave up for $$t > 0$$, that is, for $$x > 1$$.
</WorkedExample>

**Q.** For the curve $$x = t^2$$, $$y = t^{3} - 5t$$, what is $$\frac{d^2y}{dx^2}$$ at $$t = 2$$?

**A.** $$\frac{17}{32}$$. Differentiate $$\frac{dy}{dx}$$ with respect to $$t$$, then divide by $$\frac{dx}{dt} = 2t$$. $$\frac{dy}{dx} = \frac{3t^2 - 5}{2t} = \frac{3t}{2} - \frac{5}{2t}$$. Its $$t$$-derivative is $$\frac{3}{2} + \frac{5}{2t^2}$$, which is $$\frac{17}{8}$$ at $$t = 2$$. Dividing by $$2t = 4$$ gives $$\frac{17}{32}$$.

**Q.** For the curve $$x = t^2$$, $$y = t^{3} + 5t$$, what is $$\frac{d^2y}{dx^2}$$ at $$t = 1$$?
