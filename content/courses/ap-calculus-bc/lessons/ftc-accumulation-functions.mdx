Define a new function by measuring area: $$g(x) = \int_a^x f(t)\,dt$$ is the area under $$f$$ from a fixed start $$a$$ to a moving end $$x$$. How fast does that area grow? The answer, $$f(x)$$, is the first half of the most important theorem in the course.

## FTC part 1

If $$f$$ is continuous on an interval containing $$a$$, then

$$
g(x) = \int_a^x f(t)\,dt \quad\Longrightarrow\quad g'(x) = f(x).
$$

**Why:** when $$x$$ increases by a small $$h$$, the area grows by a thin strip of width $$h$$ and height about $$f(x)$$. So $$\frac{g(x + h) - g(x)}{h} \approx f(x)$$, and in the limit the approximation is exact.

## With the chain rule

If the upper limit is a function $$u(x)$$:

$$
\frac{d}{dx}\int_a^{u(x)} f(t)\,dt = f(u(x)) \cdot u'(x).
$$

If $$x$$ appears in the lower limit, flip the limits first: $$\int_{u(x)}^{a} f(t)\,dt = -\int_a^{u(x)} f(t)\,dt$$.

<Note title="The lower limit does not matter for the derivative">
Changing the constant lower limit shifts $$g$$ up or down by a constant, which does not change $$g'$$. It does change values like $$g(2)$$, so read the limits carefully when evaluating.
</Note>

<WorkedExample title="Both limits involve x">
Find $$\frac{d}{dx}\int_{x}^{x^2} \frac{1}{t}\,dt$$ for $$x > 0$$.

1. Split at a constant: $$\int_x^{x^2} = \int_1^{x^2} - \int_1^{x}$$.
2. Differentiate each: $$\frac{1}{x^2}\cdot 2x - \frac{1}{x}$$.
3. Simplify: $$\frac{2}{x} - \frac{1}{x}$$.

**Answer:** $$\frac{1}{x}$$.
</WorkedExample>

**Q.** If $$G(x) = \int_{3}^{x^{2}} e^{t}\,dt$$, then $$G'(x) =$$

**A.** $$2x^{1}e^{x^{2}}$$. By the Fundamental Theorem of Calculus with the chain rule, substitute the upper limit and multiply by its derivative. If $$G(x) = \int_{3}^{u(x)} f(t)\,dt$$, then $$G'(x) = f(u(x))\,u'(x)$$. Here $$u = x^{2}$$, so $$G'(x) = 2x^{1}e^{x^{2}}$$.

### Free-response practice: An accumulation function from a graph

The continuous function $$f$$ is defined on $$0 \leq x \leq 6$$. Its graph consists of line segments, as shown. Let $$g(x) = \int_{2}^{x} f(t)\,dt$$.

<Figure src="assets/guides/ftc-accumulation-functions-15.svg" alt="Graph of f: line segments through (0, -2), (1, 1), (2, 0), (3, -3), (4, -3), (5, 1), (6, 2)." caption="Graph for the question below." />

**(a)** Find $$g(0)$$ and $$g(6)$$.

To earn the point: Finds $$g(0)$$, reversing the limits correctly. Model answer: $$g(0) = -\int_0^{2} f(t)\,dt = 0$$

To earn the point: Finds $$g(6)$$. Model answer: $$g(6) = -4$$

**(b)** Find $$g'(0.5)$$ and $$g''(0.5)$$.

To earn the point: Uses $$g' = f$$. Model answer: $$g'(0.5) = f(0.5) = -\frac{1}{2}$$

To earn the point: Uses $$g'' = f'$$, the slope of the segment. Model answer: $$g''(0.5) = f'(0.5) = 3$$

**(c)** On the open interval $$0 < x < 6$$, find all values of $$x$$ at which $$g$$ has a relative maximum. Justify your answer.

To earn the point: Identifies the correct values (or that there are none). Model answer: $$x = 2$$

To earn the point: Justifies using a sign change of $$g' = f$$ from positive to negative. Model answer: $$g' = f$$ changes from positive to negative there.

**(d)** Find the absolute maximum value of $$g$$ on $$0 \leq x \leq 6$$. Justify your answer.

To earn the point: Considers the endpoints and every critical point (Candidates Test). Model answer: $$g(0) = 0$$, $$g(\frac{2}{3}) = -\frac{2}{3}$$, $$g(2) = 0$$, $$g(\frac{19}{4}) = -\frac{45}{8}$$, $$g(6) = -4$$

To earn the point: Gives the correct maximum value. Model answer: The absolute maximum is $$0$$, at $$x = 0$$.
