A power series is a polynomial that never ends. For some values of $$x$$ it adds up to a number; for others it blows up. Those values always form an interval centered at $$a$$.

## Finding the interval

1. **Ratio test** with $$x$$ inside: $$L(x) = \lim\left|\frac{a_{n+1}}{a_n}\right|$$.
2. Solve $$L(x) < 1$$ to get $$|x - a| < R$$. This gives the radius $$R$$.
3. **Test each endpoint** $$x = a \pm R$$ by substituting and using another test (p-series, alternating series, nth term).
4. Write the interval with the correct brackets.

## Three possible shapes

- $$R = 0$$: converges only at $$x = a$$ (as for $$\sum n!\,x^n$$).
- $$R = \infty$$: converges for all $$x$$ (as for $$\sum \frac{x^n}{n!}$$).
- $$0 < R < \infty$$: an interval, with each endpoint in or out.

<Note title="Endpoints carry real points">
Free-response rubrics give separate points for analyzing each endpoint. At an endpoint the series becomes an ordinary numerical series: name the test you use.
</Note>

<WorkedExample title="Interval of convergence">
Find the interval of convergence of $$\sum_{n=1}^{\infty} \frac{(x - 2)^n}{n}$$.

1. Ratio: $$\left|\frac{(x - 2)^{n+1}}{n + 1} \cdot \frac{n}{(x - 2)^n}\right| \to |x - 2|$$. Need $$|x - 2| < 1$$: $$1 < x < 3$$.
2. $$x = 3$$: $$\sum \frac{1}{n}$$, the harmonic series, diverges.
3. $$x = 1$$: $$\sum \frac{(-1)^n}{n}$$, converges by the alternating series test.

**Answer:** $$1 \leq x < 3$$, with radius 1.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

What is the radius of convergence of $$\sum_{n=0}^{\infty} \frac{n\,(x + 3)^n}{4^n}$$?

**Answer:** $$4$$

**Why:** The ratio test gives $$\frac{|x + 3|}{4} < 1$$.

**Working:** $$\left|\frac{(n + 1)(x + 3)^{n+1}}{4^{n+1}}\cdot\frac{4^n}{n(x + 3)^n}\right| = \frac{n + 1}{n}\cdot\frac{|x + 3|}{4} \to \frac{|x + 3|}{4}$$. Convergence needs this below 1, so $$R = 4$$.

**Mistakes to avoid**

- $$\frac{1}{4}$$: The radius is the reciprocal of this.
- $$3$$: The center is not the radius.
- $$\infty$$: The series converges for all x only when the ratio limit is 0 for every x.

### Worked exam question 2

What is the interval of convergence of $$\sum_{n=1}^{\infty} \frac{(x + 3)^n}{n\cdot 2^n}$$?

**Answer:** $$-5 \leq x < -1$$

**Why:** Ratio test gives $$|x + 3| < 2$$; the left endpoint gives an alternating harmonic series (converges), the right endpoint the harmonic series (diverges).

**Working:** Ratio: $$\left|\frac{(x + 3)^{n+1}}{(n + 1)2^{n+1}}\cdot\frac{n\,2^n}{(x + 3)^n}\right| \to \frac{|x + 3|}{2}$$, so $$|x + 3| < 2$$. At $$x = -1$$: $$\sum \frac{1}{n}$$ diverges. At $$x = -5$$: $$\sum \frac{(-1)^n}{n}$$ converges.

**Mistakes to avoid**

- $$-5 < x < -1$$: The left endpoint gives $$\sum \frac{(-1)^n}{n}$$, which converges.
- $$-5 < x \leq -1$$: The endpoints are reversed: the right endpoint gives the divergent harmonic series.
- $$-4 < x < -2$$: The radius is 2, from the factor $$2^n$$.

### Free-response practice: A power series

The function $$f$$ is defined by the power series $$f(x) = \sum_{n=1}^{\infty} \frac{(-1)^{n+1}x^n}{n\cdot 2^n} = \frac{x}{2} - \frac{x^2}{2\cdot 4} + \frac{x^3}{3\cdot 8} - \cdots$$ for all $$x$$ in its interval of convergence.

**(a)** Find the interval of convergence of the series. Show the work that leads to your answer.

To earn the point: Sets up the ratio test. Model answer: $$\left|\frac{x^{n+1}}{(n + 1)2^{n+1}}\cdot\frac{n\,2^n}{x^n}\right| \to \frac{|x|}{2}$$

To earn the point: Finds the radius. Model answer: $$|x| < 2$$

To earn the point: Analyzes both endpoints with a test. Model answer: At $$x = 2$$: $$\sum \frac{(-1)^{n+1}}{n}$$ converges (alternating series test). At $$x = -2$$: $$-\sum \frac{1}{n}$$ diverges (harmonic).

To earn the point: Gives the interval. Model answer: $$-2 < x \leq 2$$

**(b)** Find the first three nonzero terms and the general term of the Maclaurin series for $$f'(x)$$. Then write $$f'(x)$$ as a rational function.

To earn the point: Differentiates term by term. Model answer: $$f'(x) = \frac{1}{2} - \frac{x}{4} + \frac{x^2}{8} - \cdots + \frac{(-1)^{n+1}x^{n-1}}{2^n} + \cdots$$

To earn the point: Recognizes a geometric series. Model answer: $$\frac{1/2}{1 + x/2} = \frac{1}{2 + x}$$

**(c)** Use the first two nonzero terms of the series to approximate $$f(1)$$. Show that this approximation differs from $$f(1)$$ by less than $$0.063$$.

To earn the point: Gives the approximation. Model answer: $$\frac{1}{2} - \frac{1}{8} = \frac{3}{8}$$

To earn the point: Uses the alternating series error bound with justification. Model answer: The series at $$x = 1$$ alternates with terms decreasing to 0, so the error is at most the third term, $$\frac{1}{3\cdot 8} = \frac{1}{24}$$.
