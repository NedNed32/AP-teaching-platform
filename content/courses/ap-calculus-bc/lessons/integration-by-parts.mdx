Substitution undoes the chain rule. Integration by parts undoes the **product rule**, which makes it the tool for integrals like $$\int x\cos x\,dx$$ or $$\int \ln x\,dx$$.

## The formula

From $$(uv)' = u'v + uv'$$, integrate and rearrange:

$$
\int u\,dv = uv - \int v\,du.
$$

Pick part of the integrand to be $$u$$ (you will differentiate it) and the rest to be $$dv$$ (you will integrate it). The goal is a new integral $$\int v\,du$$ that is easier than the original.

## Choosing u

Use **LIATE**: choose $$u$$ as the first type on this list that appears.

| Type | Example |
| --- | --- |
| Logarithmic | $$\ln x$$ |
| Inverse trig | $$\arctan x$$ |
| Algebraic | $$x^2$$ |
| Trigonometric | $$\sin x$$ |
| Exponential | $$e^{3x}$$ |

Logarithms and inverse trig functions have simple derivatives but awkward antiderivatives, so they make good choices for $$u$$.

## Repeated parts and tabular integration

For $$\int x^2 e^x\,dx$$, parts must be used twice. A tidy shortcut is a **table**: differentiate $$x^2$$ down to 0 in one column, integrate $$e^x$$ in the other, and combine diagonally with alternating signs:

$$
\int x^2 e^x\,dx = x^2e^x - 2xe^x + 2e^x + C.
$$

<Note title="Definite integrals">
For definite integrals, evaluate the $$uv$$ term at the limits too: $$\int_a^b u\,dv = \left[uv\right]_a^b - \int_a^b v\,du$$.
</Note>

<WorkedExample title="A trigonometric product">
Find $$\int x\cos(2x)\,dx$$.

1. $$u = x$$, $$du = dx$$; $$dv = \cos(2x)\,dx$$, $$v = \frac{1}{2}\sin(2x)$$.
2. $$\int x\cos(2x)\,dx = \frac{x}{2}\sin(2x) - \int \frac{1}{2}\sin(2x)\,dx$$.
3. $$\int \frac{1}{2}\sin(2x)\,dx = -\frac{1}{4}\cos(2x)$$.

**Answer:** $$\frac{x}{2}\sin(2x) + \frac{1}{4}\cos(2x) + C$$.
</WorkedExample>

## On the practice exams

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** $$\int xe^{x}\,dx =$$

**A.** $$xe^{x} - e^{x} + C$$. Parts with $$u = x$$ and $$dv = e^{x}\,dx$$. $$u = x,\; du = dx,\; v = \frac{1}{1}e^{x}$$. Then $$\int xe^{x}\,dx = \frac{x}{1}e^{x} - \int \frac{1}{1}e^{x}\,dx = xe^{x} - e^{x} + C$$.

**Q.** What is $$\int_0^{\pi} x\sin x\,dx$$?

**A.** $$\pi$$. Integration by parts, then evaluate at both limits. Use integration by parts: $$\left[-x\cos x + \sin x\right]_0^{\pi} = \pi$$.

**Q.** $$\int xe^{3x}\,dx =$$

**A.** $$\frac{1}{3}xe^{3x} - \frac{1}{9}e^{3x} + C$$. Parts with $$u = x$$ and $$dv = e^{3x}\,dx$$. $$u = x,\; du = dx,\; v = \frac{1}{3}e^{3x}$$. Then $$\int xe^{3x}\,dx = \frac{x}{3}e^{3x} - \int \frac{1}{3}e^{3x}\,dx = \frac{1}{3}xe^{3x} - \frac{1}{9}e^{3x} + C$$.

**Q.** $$\int xe^{2x}\,dx =$$

**A.** $$\frac{1}{2}xe^{2x} - \frac{1}{4}e^{2x} + C$$. Parts with $$u = x$$ and $$dv = e^{2x}\,dx$$. $$u = x,\; du = dx,\; v = \frac{1}{2}e^{2x}$$. Then $$\int xe^{2x}\,dx = \frac{x}{2}e^{2x} - \int \frac{1}{2}e^{2x}\,dx = \frac{1}{2}xe^{2x} - \frac{1}{4}e^{2x} + C$$.

**Q.** What is $$\int_0^{\pi/2} x\cos x\,dx$$?

**A.** $$\frac{\pi}{2} - 1$$. Integration by parts, then evaluate at both limits. Use integration by parts: $$\left[x\sin x + \cos x\right]_0^{\pi/2} = \frac{\pi}{2} - 1$$.

**Q.** What is $$\int_1^{e} \ln x\,dx$$?

**A.** $$1$$. Integration by parts, then evaluate at both limits. Use integration by parts: $$\left[x\ln x - x\right]_1^{e} = (e - e) - (0 - 1) = 1$$.

**Q.** What is $$\int_0^{1} xe^{x}\,dx$$?

**A.** $$1$$. Integration by parts, then evaluate at both limits. Use integration by parts: $$\left[xe^x - e^x\right]_0^1 = 0 - (-1) = 1$$.

**Q.** $$\int xe^{4x}\,dx =$$

**A.** $$\frac{1}{4}xe^{4x} - \frac{1}{16}e^{4x} + C$$. Parts with $$u = x$$ and $$dv = e^{4x}\,dx$$. $$u = x,\; du = dx,\; v = \frac{1}{4}e^{4x}$$. Then $$\int xe^{4x}\,dx = \frac{x}{4}e^{4x} - \int \frac{1}{4}e^{4x}\,dx = \frac{1}{4}xe^{4x} - \frac{1}{16}e^{4x} + C$$.
