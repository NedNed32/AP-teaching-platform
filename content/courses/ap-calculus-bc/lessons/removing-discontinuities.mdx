A removable discontinuity is a hole that can be filled. Because the limit exists, you can define (or redefine) the function at that one point to equal the limit, and the graph becomes unbroken.

## Filling a hole

$$f(x) = \frac{x^2 - 5x + 6}{x - 3}$$ is undefined at 3. Since $$f(x) = x - 2$$ for $$x \neq 3$$, $$\lim_{x \to 3} f(x) = 1$$. The function

$$
g(x) = \begin{cases} \dfrac{x^2 - 5x + 6}{x - 3} & x \neq 3 \\ 1 & x = 3 \end{cases}
$$

is continuous everywhere.

## Solving for a constant

A common exam task gives a piecewise function with an unknown constant and asks for the value that makes it continuous. Set the one-sided limits equal at the break point and solve.

<Note title="Two unknowns need two conditions">
If a piecewise function has two unknown constants, continuity at a point gives one equation. A second equation usually comes from differentiability: the one-sided derivatives must also match (topic 2.4).
</Note>

<WorkedExample title="Making a piecewise function continuous">
For what value of $$k$$ is $$f(x) = \begin{cases} kx^2 - 3 & x < 2 \\ 4x + k & x \geq 2 \end{cases}$$ continuous at $$x = 2$$?

1. Left-hand limit: $$4k - 3$$.
2. Right-hand limit and value: $$8 + k$$.
3. Set them equal: $$4k - 3 = 8 + k$$, so $$3k = 11$$.

**Answer:** $$k = \frac{11}{3}$$.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Let $$f(x) = \begin{cases} kx + 14 & x < 2 \\ x^{2} + 4 & x \geq 2 \end{cases}$$ where $$k$$ is a constant. For what value of $$k$$ is $$f$$ continuous at $$x = 2$$?

**Answer:** $$-3$$

**Why:** Continuity needs $$k(2) + 14 = (2)^2 + 4$$, which gives $$k = -3$$.

**Working:** $$f$$ is continuous at $$2$$ when the left-hand limit equals $$f(2) = 8$$. The left-hand limit is $$2k + 14$$, so $$2k + 14 = 8$$ and $$k = -3$$.

**Mistakes to avoid**

- $$11$$: This comes from a sign error when moving the constant term across the equation.
- $$4$$: This matches the slopes of the two pieces, which is the condition for differentiability, not continuity.
- $$-6$$: This forgets to divide by $$2$$ when solving for $$k$$.

**Q.** The function $$g$$ is defined by $$g(x) = \frac{\sin(3x)}{e^{4x} - 1}$$ for $$x \neq 0$$. For what value of $$g(0)$$ is $$g$$ continuous at $$x = 0$$?

**A.** $$0.750$$. Evaluating $$g$$ at inputs very close to 0 (or using the limits of $$\frac{\sin u}{u}$$ and $$\frac{e^u - 1}{u}$$) gives $$\frac{3}{4}$$. For continuity, $$g(0)$$ must equal $$\lim_{x \to 0} g(x)$$. Near 0, $$\sin(3x) \approx 3x$$ and $$e^{4x} - 1 \approx 4x$$, so the limit is $$\frac{3}{4} \approx 0.750$$. A table of values near 0 confirms it.
