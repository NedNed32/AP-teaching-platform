A separable differential equation is one of the most reliable free-response questions: it is worth about five points, and every point follows a fixed sequence of steps.

## The scoring sequence

1. **Separate** the variables correctly.
2. **Antidifferentiate** both sides.
3. **Include the constant** of integration.
4. **Use the initial condition** to find $$C$$.
5. **Solve for $$y$$**.

Graders follow these steps in order. A mistake in separating usually caps the score, so check that step carefully.

## Choosing the sign

After solving, you may get $$y = \pm\sqrt{\ldots}$$ or $$|y| = \ldots$$. The initial condition decides: if $$y(0) = 3 > 0$$, take the positive branch.

## Domain

A particular solution is defined on the largest interval containing the initial point where the formula makes sense. For example, $$y = \frac{1}{1 - x}$$ with $$y(0) = 1$$ is defined on $$x < 1$$.

<Note title="Substitute early">
Plug in the initial condition right after integrating, while you have something like $$\ln|y| = x^2 + C$$. Solving for $$y$$ first introduces $$e^C$$ and absolute values that make the arithmetic messier.
</Note>

<WorkedExample title="A full particular solution">
Find the solution of $$\frac{dy}{dx} = \frac{x + 1}{y}$$ with $$y(0) = -3$$.

1. Separate: $$y\,dy = (x + 1)\,dx$$.
2. Integrate: $$\frac{y^2}{2} = \frac{x^2}{2} + x + C$$.
3. Initial condition: $$\frac{9}{2} = 0 + 0 + C$$, so $$C = \frac{9}{2}$$.
4. Solve: $$y^2 = x^2 + 2x + 9$$, so $$y = \pm\sqrt{x^2 + 2x + 9}$$.
5. Since $$y(0) = -3 < 0$$, take the negative root.

**Answer:** $$y = -\sqrt{x^2 + 2x + 9}$$.
</WorkedExample>

**Q.** Which of the following is the solution to $$\frac{dy}{dx} = \frac{x}{y}$$ with $$y(0) = 6$$?

**A.** $$y = \sqrt{x^2 + 36}$$. $$y\,dy = x\,dx$$ gives $$y^2 = x^2 + C$$; $$C = 36$$, and the positive root matches $$y(0) = 6$$. Separate: $$\int y\,dy = \int x\,dx$$, so $$\frac{y^2}{2} = \frac{x^2}{2} + C$$. With $$y(0) = 6$$, $$y^2 = x^2 + 36$$ and $$y = \sqrt{x^2 + 36}$$.

**Q.** Which of the following is the solution to the differential equation $$\frac{dy}{dx} = -y$$ with initial condition $$y(0) = 3$$?

**A.** $$y = 3e^{-x}$$. Separating, $$\ln|y| = -x + C$$, so $$y = Ce^{-x}$$ and $$C = 3$$. $$\frac{dy}{y} = -1\,dx$$, so $$\ln|y| = -x + C$$ and $$y = Ae^{-x}$$. The initial condition gives $$A = 3$$.

### Free-response practice: A differential equation

Consider the differential equation $$\frac{dy}{dx} = 4x(y - 1)$$. Let $$y = f(x)$$ be the particular solution with $$f(1) = 2$$.

**(a)** Find the slope of the slope-field segment at each of the points $$(-1, 2)$$, $$(0, 3)$$, $$(1, 0)$$ and $$(2, 1)$$.

To earn the point: Gives all four slopes correctly. Model answer: $$(-1, 2): -4$$; $$(0, 3): 0$$; $$(1, 0): -4$$; $$(2, 1): 0$$

**(b)** Write an equation for the line tangent to the graph of $$f$$ at $$x = 1$$, and use it to approximate $$f(1.2)$$.

To earn the point: Finds the slope at the point and writes the tangent line. Model answer: $$\frac{dy}{dx}\Big|_{(1, 2)} = 4$$; $$y = 2 + 4(x - 1)$$

To earn the point: Gives the approximation. Model answer: $$f(1.2) \approx 2.8$$

**(c)** Find $$\frac{d^2y}{dx^2}$$ in terms of $$x$$ and $$y$$. Is the approximation in part (b) an overestimate or an underestimate? Explain.

To earn the point: Finds the second derivative. Model answer: $$\frac{d^2y}{dx^2} = 4(y - 1) + 4x\frac{dy}{dx} = 4(y - 1)(1 + 4x^2)$$

To earn the point: Uses the sign of the second derivative at the point to conclude. Model answer: At $$(1, 2)$$, $$\frac{d^2y}{dx^2} = 20$$, so f is concave up and the tangent line lies below the curve: an underestimate.

**(d)** Find the particular solution $$y = f(x)$$ with $$f(1) = 2$$.

To earn the point: Separates the variables. Model answer: $$\frac{dy}{y - 1} = 4x\,dx$$

To earn the point: Antidifferentiates both sides. Model answer: $$\ln|y - 1| = 2x^2 + C$$

To earn the point: Uses the initial condition. Model answer: $$C = \ln1 - 2$$

To earn the point: Solves for $$y$$. Model answer: $$y = 1 + e^{2(x^2 - 1)}$$
