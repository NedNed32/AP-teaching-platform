One of the most common free-response questions gives the graph of a function $$f$$ made of lines and semicircles, defines $$g(x) = \int_a^x f(t)\,dt$$, and asks about $$g$$. Two facts answer almost every part.

<Figure src="assets/lessons/signed-area.svg" alt="A sine-like curve with the region above the axis on the first hump shaded and marked plus, and the region below the axis on the second hump shaded and marked minus." caption="Area above the axis adds to g; area below subtracts." />

## Fact 1: values of g are signed areas

$$g(b) = \int_a^b f(t)\,dt$$: add the areas above the axis and subtract the areas below, between $$a$$ and $$b$$. If $$b < a$$, the integral runs backwards, so reverse the sign.

## Fact 2: g prime is f and g double prime is f prime

So the graph of $$f$$ acts as the graph of $$g'$$:

| Graph of $$f$$ | Behavior of $$g$$ |
| --- | --- |
| above the axis | $$g$$ increasing |
| crosses from $$+$$ to $$-$$ | $$g$$ has a relative maximum |
| crosses from $$-$$ to $$+$$ | $$g$$ has a relative minimum |
| increasing | $$g$$ concave up |
| has a peak or valley | $$g$$ has an inflection point |

<Note title="Absolute extrema of g">
Use the Candidates Test: evaluate $$g$$ at the endpoints and wherever $$f$$ changes sign, using areas. Compare the values.
</Note>

<WorkedExample title="Values and extrema from areas">
The graph of $$f$$ is a line from $$(0, 2)$$ to $$(2, -2)$$, then a horizontal segment at $$-2$$ to $$x = 4$$. Let $$g(x) = \int_0^x f(t)\,dt$$. Find $$g(4)$$ and the absolute maximum of $$g$$ on $$[0, 4]$$.

1. Triangle above the axis on $$[0, 1]$$: area 1. Triangle below on $$[1, 2]$$: area 1. Rectangle below on $$[2, 4]$$: area 4.
2. $$g(4) = 1 - 1 - 4 = -4$$.
3. $$f$$ changes from positive to negative at $$x = 1$$, so candidates are $$g(0) = 0$$, $$g(1) = 1$$, $$g(4) = -4$$.

**Answer:** $$g(4) = -4$$; the absolute maximum of $$g$$ is 1, at $$x = 1$$.
</WorkedExample>

### Free-response practice: An accumulation function from a graph

The continuous function $$f$$ is defined on $$0 \leq x \leq 6$$. Its graph consists of line segments, as shown. Let $$g(x) = \int_{2}^{x} f(t)\,dt$$.

<Figure src="assets/guides/accumulation-functions-behavior-15.svg" alt="Graph of f: line segments through (0, -2), (1, 1), (2, 0), (3, -3), (4, -3), (5, 1), (6, 2)." caption="Graph for the question below." />

**(a)** Find $$g(0)$$ and $$g(6)$$.

To earn the point: Finds $$g(0)$$, reversing the limits correctly. Model answer: $$g(0) = -\int_0^{2} f(t)\,dt = 0$$

To earn the point: Finds $$g(6)$$. Model answer: $$g(6) = -4$$

**(b)** Find $$g'(0.5)$$ and $$g''(0.5)$$.

To earn the point: Uses $$g' = f$$. Model answer: $$g'(0.5) = f(0.5) = -\frac{1}{2}$$

To earn the point: Uses $$g'' = f'$$, the slope of the segment. Model answer: $$g''(0.5) = f'(0.5) = 3$$

**(c)** On the open interval $$0 < x < 6$$, find all values of $$x$$ at which $$g$$ has a relative maximum. Justify your answer.

To earn the point: Identifies the correct values (or that there are none). Model answer: $$x = 2$$

To earn the point: Justifies using a sign change of $$g' = f$$ from positive to negative. Model answer: $$g' = f$$ changes from positive to negative there.

**(d)** Find the absolute maximum value of $$g$$ on $$0 \leq x \leq 6$$. Justify your answer.

To earn the point: Considers the endpoints and every critical point (Candidates Test). Model answer: $$g(0) = 0$$, $$g(\frac{2}{3}) = -\frac{2}{3}$$, $$g(2) = 0$$, $$g(\frac{19}{4}) = -\frac{45}{8}$$, $$g(6) = -4$$

To earn the point: Gives the correct maximum value. Model answer: The absolute maximum is $$0$$, at $$x = 0$$.
