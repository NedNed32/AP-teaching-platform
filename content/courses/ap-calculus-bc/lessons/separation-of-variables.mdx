When the right side of a differential equation factors into an $$x$$ part times a $$y$$ part, you can solve it exactly: separate the variables, then integrate both sides.

## The method

For $$\frac{dy}{dx} = g(x)\,h(y)$$:

1. **Separate:** $$\frac{1}{h(y)}\,dy = g(x)\,dx$$. All $$y$$ terms with $$dy$$, all $$x$$ terms with $$dx$$.
2. **Integrate both sides:** $$\int \frac{1}{h(y)}\,dy = \int g(x)\,dx$$.
3. **Add one constant** $$C$$ (on the $$x$$ side).
4. **Solve for $$y$$** if possible.

## Exponential solutions

For $$\frac{dy}{dx} = ky$$:

$$
\int \frac{1}{y}\,dy = \int k\,dx \;\Rightarrow\; \ln|y| = kx + C \;\Rightarrow\; |y| = e^{C}e^{kx} \;\Rightarrow\; y = Ae^{kx}.
$$

The constant changes form along the way; that is fine as long as it stays an arbitrary constant.

<Note title="Never separate a sum">
$$\frac{dy}{dx} = x + y$$ is **not** separable: you cannot write it as $$(\ldots x\ldots)(\ldots y\ldots)$$. Attempting to separate it anyway earns no credit.
</Note>

<WorkedExample title="A general solution">
Find the general solution of $$\frac{dy}{dx} = 2x\,y^2$$.

1. Separate: $$y^{-2}\,dy = 2x\,dx$$.
2. Integrate: $$-y^{-1} = x^2 + C$$.
3. Solve: $$y = -\frac{1}{x^2 + C}$$.

**Answer:** $$y = -\frac{1}{x^2 + C}$$ (plus the constant solution $$y = 0$$, lost when dividing by $$y^2$$).
</WorkedExample>

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** Which of the following is the solution to $$\frac{dy}{dx} = \frac{x}{y}$$ with $$y(0) = 6$$?

**A.** $$y = \sqrt{x^2 + 36}$$. $$y\,dy = x\,dx$$ gives $$y^2 = x^2 + C$$; $$C = 36$$, and the positive root matches $$y(0) = 6$$. Separate: $$\int y\,dy = \int x\,dx$$, so $$\frac{y^2}{2} = \frac{x^2}{2} + C$$. With $$y(0) = 6$$, $$y^2 = x^2 + 36$$ and $$y = \sqrt{x^2 + 36}$$.

**Q.** Which of the following is the solution to the differential equation $$\frac{dy}{dx} = -y$$ with initial condition $$y(0) = 3$$?

**A.** $$y = 3e^{-x}$$. Separating, $$\ln|y| = -x + C$$, so $$y = Ce^{-x}$$ and $$C = 3$$. $$\frac{dy}{y} = -1\,dx$$, so $$\ln|y| = -x + C$$ and $$y = Ae^{-x}$$. The initial condition gives $$A = 3$$.
