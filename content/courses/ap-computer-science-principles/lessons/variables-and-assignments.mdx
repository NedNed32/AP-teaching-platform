The AP exam writes code in its own **pseudocode**, described on the exam reference sheet. Assignment uses an arrow.

## Assignment

```text
a ← 5
b ← a + 2
a ← b * 3
DISPLAY (a)
```

Evaluate the right side using current values, then store it in the variable on the left. Here b is 7 and a becomes 21, so 21 is displayed.

Use meaningful names (`score`, `totalCost`) so code explains itself. Variables can hold numbers, Booleans, strings or lists.

<Note title="One value at a time">
A variable holds only its most recent value. Assigning to it again replaces the old value.
</Note>

<WorkedExample title="Swapping values">
What is displayed?

```text
x ← 4
y ← 9
x ← y
y ← x
DISPLAY (x)
DISPLAY (y)
```

1. After `x ← y`, x is 9; the 4 is lost.
2. `y ← x` stores 9 in y.

**Answer:** 9 9. A correct swap needs a temporary variable.
</WorkedExample>
