**Iteration** repeats statements. AP pseudocode has two loop forms (plus FOR EACH for lists).

## REPEAT n TIMES

```text
total ← 0
REPEAT 4 TIMES
{
   total ← total + 5
}
DISPLAY (total)       // 20
```

## REPEAT UNTIL

```text
n ← 1
REPEAT UNTIL (n > 50)
{
   n ← n * 3
}
DISPLAY (n)           // 1, 3, 9, 27, 81: displays 81
```

The condition is checked **before** each pass. The loop stops as soon as the condition is true.

<Note title="Infinite loops">
If the body never moves the loop toward its stopping condition, it runs forever. For example, `REPEAT UNTIL (x = 10)` with x starting at 1 and increasing by 2 never stops, because x is always odd.
</Note>

<WorkedExample title="Counting passes">
How many times does the loop body run?

```text
x ← 100
REPEAT UNTIL (x < 10)
{
   x ← x / 2
}
```

1. x: 100, 50, 25, 12.5, 6.25. The check fails four times, then 6.25 stops it.

**Answer:** 4 times.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Consider the following code segment.

```text
n ← 1
count ← 0
REPEAT UNTIL (n > 44)
{
   n ← n * 3 + 3
   count ← count + 1
}
DISPLAY (count)
DISPLAY (n)
```

What is displayed as a result of running the code segment?

**Answer:** `3 66`

**Why:** The condition is checked before each pass, and the loop stops once n exceeds the limit.

**Working:** n takes the values 1, 6, 21, 66; the loop body runs 3 times.

**Mistakes to avoid**

- `2 21`: The loop runs once more, because the condition is still false at that point.
- `4 201`: The loop stops as soon as the condition is true.
- `3 21`: n is updated in the last pass too.

### Worked exam question 2

A robot is on a 6-by-6 grid of squares. Rows are numbered 1 to 6 from top to bottom and columns 1 to 6 from left to right. The robot starts in row 5, column 3, facing up. `MOVE_FORWARD()` moves it one square in the direction it faces; `ROTATE_LEFT()` and `ROTATE_RIGHT()` turn it 90 degrees in place.

```text
REPEAT 2 TIMES
{
   MOVE_FORWARD()
   ROTATE_RIGHT()
}
```

Where does the robot end, and which way does it face?

**Answer:** Row 4, column 4, facing down

**Why:** Trace each move and turn in order.

**Working:** Tracing 2 passes of 1 move then ROTATE_RIGHT ends at row 4, column 4, facing down.

**Mistakes to avoid**

- Row 4, column 2, facing down: ROTATE_RIGHT turns the robot clockwise.
- Row 4, column 4, facing up: The robot turns in every pass, including the last.
- Row 5, column 3, facing down: The robot moves forward in each pass.
