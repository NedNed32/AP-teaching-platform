Data becomes useful when we find **information** in it: trends, patterns and relationships.

## Tools for insight

- **Filtering, sorting and grouping** narrow a data set.
- **Visualizations** such as charts and maps reveal patterns.
- **Metadata** helps organize and find data. Changing or deleting metadata does not change the primary data.

## Challenges

- Data may be **incomplete** or **invalid** and need **cleaning**, for example standardizing "NY", "N.Y." and "New York".
- Data may be **biased** if the collection method left groups out. Collecting more data the same way does not remove the bias.
- Large data sets need **scalable** systems; one computer may be too slow.
- A **correlation** does not establish causation.

<WorkedExample title="Correlation and cause">
Cities with more ice cream sales also have more sunburns. Does ice cream cause sunburn?

1. Both increase in hot, sunny weather.
2. A third factor explains the correlation.

**Answer:** no; the data shows only a correlation.
</WorkedExample>

## On the practice exams

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** A data set from a school library contains one row per transaction with these fields: book title, genre, checkout date, return date. Which question can be answered using only this data?

**A.** What is the average number of days a book is kept?. Every field it needs is in the data set. Only "What is the average number of days a book is kept?" can be answered from the listed fields; each other question needs data that was not collected.

**Q.** A data set from a bike-share service contains one row per transaction with these fields: start station, end station, start time, trip length in minutes. Which question can be answered using only this data?

**A.** Which station is the most common starting point?. Every field it needs is in the data set. Only "Which station is the most common starting point?" can be answered from the listed fields; each other question needs data that was not collected.

**Q.** A data set from an online store contains one row per transaction with these fields: product name, category, price, date of sale. Which question can be answered using only this data?

**A.** Which category has the most sales?. Every field it needs is in the data set. Only "Which category has the most sales?" can be answered from the listed fields; each other question needs data that was not collected.

**Q.** A photo file includes the date it was taken and the camera's location. What is this additional information called?

**A.** Metadata. Data about data is metadata.

**Q.** A data set records states as "CA", "Calif." and "California". What should be done before counting entries by state?

**A.** Clean the data so each state is written the same way. Cleaning makes data uniform without changing its meaning.

**Q.** Sound is sampled 44,100 times per second to store it digitally. What is the effect of sampling more often?

**A.** The digital version is a closer approximation of the analog sound, but uses more storage. More samples capture more detail at the cost of size.

**Q.** Which is a consequence of representing real numbers with a fixed number of bits?

**A.** Some values can only be approximated, causing round-off errors. Limited precision means some real numbers are approximated.

**Q.** A survey collected only from people who use a particular app is used to describe the whole population. What is the main problem?

**A.** The sample may be biased, so the results may not represent everyone. Data collected from one group may not apply to others.

**Q.** A researcher finds that students who sleep more also have higher test scores. Which conclusion is justified?

**A.** Sleep and scores are correlated, but the data alone does not show that sleep causes higher scores. Correlation does not imply causation.
