**Selection** lets an algorithm make decisions.

## IF and IF-ELSE

```text
IF (score ≥ 60)
{
   DISPLAY ("pass")
}
ELSE
{
   DISPLAY ("retake")
}
```

The condition is evaluated once. If true, the first block runs; otherwise the ELSE block runs.

<Note title="Sequence of IFs versus IF-ELSE">
Two separate IF statements are both checked, so both blocks may run. An IF-ELSE runs exactly one block.
</Note>

<WorkedExample title="Trace">
What is displayed when n is 12?

```text
result ← 0
IF (n MOD 2 = 0)
{
   result ← result + 1
}
IF (n MOD 3 = 0)
{
   result ← result + 10
}
DISPLAY (result)
```

1. 12 is even: result is 1.
2. 12 is divisible by 3: result is 11.

**Answer:** 11. Both IF statements are checked.
</WorkedExample>

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** Consider the following code segment. ```text x ← 0 total ← 0 REPEAT 5 TIMES { x ← x + 1 IF (x MOD 2 = 0) { total ← total + x } } DISPLAY (total) ``` What is displayed as a result of running the code segment?

**A.** `6`. x goes from 1 to 5; the multiples of 2 among them are added. The values of x are 1, 2, 3, 4, 5; the multiples of 2 add to 6.
