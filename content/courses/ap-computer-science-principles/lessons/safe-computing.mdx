Personal information is valuable, which makes it a target.

## Threats

| Threat | How it works |
| --- | --- |
| phishing | fake messages or sites trick users into revealing information |
| malware and viruses | harmful software, often spread by downloads or attachments |
| keylogging | records keystrokes to capture passwords |
| rogue access point | a fake wireless network that intercepts traffic |

**Personally identifiable information** (PII), such as addresses and ID numbers, can be combined from many sources to build a detailed profile of a person.

## Protections

- **Strong passwords** and **multifactor authentication**.
- **Encryption**: symmetric encryption uses one shared key; public key encryption uses a public key to encrypt and a private key to decrypt.
- **Certificate authorities** verify that a website's public key really belongs to it.
- Antivirus software, updates, and caution with links and attachments.

<Note title="Data never really disappears">
Information posted online can be copied and stored indefinitely. Think before sharing.
</Note>

<WorkedExample title="Sending a secret">
Ana wants to send Ben an encrypted message using public key encryption. Which key should she use?

1. Anyone may encrypt with Ben's public key.
2. Only Ben's private key can decrypt it.

**Answer:** Ana encrypts with Ben's public key; Ben decrypts with his private key.
</WorkedExample>

## On the practice exams

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** Why is multifactor authentication more secure than a password alone?

**A.** An attacker who steals the password still needs another factor, such as a code on the user's phone. Multiple kinds of evidence are required.

**Q.** A user receives an email that looks like it is from their bank, asking them to click a link and enter their password. What is this attack called?

**A.** Phishing. Phishing tricks people into revealing information.

**Q.** In public key encryption, which key does a sender use to encrypt a message for a recipient?

**A.** The recipient's public key. Anyone can encrypt with the public key; only the private key decrypts.

**Q.** A coffee shop customer connects to a free network named after the shop, but it was set up by an attacker to capture traffic. What is this?

**A.** A rogue access point. A fake wireless network can intercept data.

**Q.** Which is an example of personally identifiable information (PII)?

**A.** A person's home address. PII can identify a specific person.

**Q.** How does symmetric encryption differ from public key encryption?

**A.** Symmetric encryption uses the same key to encrypt and decrypt. Public key encryption uses a pair of different keys.

**Q.** What does a certificate authority do?

**A.** Verifies that a website's public key belongs to that website. This lets users trust encrypted connections.

**Q.** Software secretly installed on a computer records every key the user presses. What is this?

**A.** A keylogger. Keylogging captures keystrokes, including passwords.
