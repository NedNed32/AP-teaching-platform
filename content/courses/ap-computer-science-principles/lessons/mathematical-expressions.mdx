An **algorithm** is a finite set of instructions. Every algorithm can be built from three parts: **sequencing**, **selection** and **iteration**. This lesson covers sequencing and arithmetic.

## Operators

| Operator | Meaning | Example |
| --- | --- | --- |
| + − * / | arithmetic | 7 / 2 is 3.5 |
| MOD | remainder | 17 MOD 5 is 2 |

MOD has the same precedence as * and /. Parentheses come first, then *, /, MOD, then + and −.

## Uses of MOD

- `n MOD 2 = 0` tests whether n is even.
- `n MOD 10` gives the last digit.
- Wrapping around: `(day + 3) MOD 7`.

<WorkedExample title="Evaluate in order">
What is displayed?

```text
a ← 14
b ← a MOD 4 + 3 * 2
a ← b - a / 7
DISPLAY (a)
```

1. 14 MOD 4 is 2; 3 * 2 is 6; b is 8.
2. a / 7 is 2; a becomes 8 − 2 = 6.

**Answer:** 6.
</WorkedExample>

### Worked exam question 1

Consider the following code segment.

```text
x ← 72
result ← x MOD 9 * 2
DISPLAY (result)
```

What is displayed as a result of running the code segment?

**Answer:** `0`

**Why:** 72 MOD 9 is 0, then multiplied by 2.

**Working:** 72 MOD 9 = 0; 0 × 2 = 0.

**Mistakes to avoid**

- `16`: MOD gives the remainder, not the quotient.
- `1`: Recheck the remainder.
- `7`: Only the given expression is evaluated.
