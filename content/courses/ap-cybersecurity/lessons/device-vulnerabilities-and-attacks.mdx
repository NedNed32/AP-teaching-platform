| Malware | Behavior |
| --- | --- |
| virus | attaches to files, spreads when they run |
| worm | self-propagates across networks |
| trojan | disguised as legitimate software |
| ransomware | encrypts files, demands payment |
| spyware / keylogger | secretly records activity |
| rootkit | hides deep in the system to keep access |
| botnet agent | lets an attacker control the device remotely |

## Device vulnerabilities

Outdated operating systems and apps, default passwords, unnecessary services, excessive user privileges, disabled security software, and lost or stolen unencrypted devices.

<Note title="Patch quickly">
Many major outbreaks used vulnerabilities that had patches available for months. Patch management is one of the most effective controls.
</Note>

<WorkedExample title="Classify the malware">
A free game download secretly installs software that sends the user's keystrokes to a remote server. What two types are involved?

1. It is disguised as something legitimate.
2. It records keystrokes.

**Answer:** a trojan delivering a keylogger (spyware).
</WorkedExample>

## On the practice exams

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** A laptop containing customer data is stolen from a car. Which control would best protect the data?

**A.** Full-disk encryption. Without the key, the data cannot be read.

**Q.** Ransomware encrypts a company's files. Which preparation allows recovery without paying?

**A.** Recent, offline backups that are tested regularly. Clean backups restore the data.

**Q.** Malware spreads automatically from computer to computer across a network without any user action. What type is it?

**A.** A worm. Worms self-propagate.

**Q.** Why should employees use standard user accounts rather than administrator accounts for daily work?

**A.** Malware running under a standard account has fewer privileges to damage the system. Least privilege limits damage.

**Q.** Which action most reduces the risk of attackers exploiting known software vulnerabilities?

**A.** Applying security patches promptly. Patches fix known vulnerabilities.

**Q.** Which is the best example of device hardening?

**A.** Disabling unused services and closing unneeded ports. Hardening reduces the attack surface.
