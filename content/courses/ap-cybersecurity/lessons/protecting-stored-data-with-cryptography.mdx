| Tool | Protects | Reversible? |
| --- | --- | --- |
| symmetric encryption (AES) | confidentiality | yes, with the key |
| hashing (SHA-256) | integrity | no |

## Encryption at rest

Full-disk encryption and encrypted databases keep data confidential if devices are stolen. The key must be protected; whoever has it can decrypt.

## Hashing

- Verify file integrity by comparing hashes.
- Store passwords as **salted hashes**, using slow algorithms designed for passwords (bcrypt, Argon2). Salts defeat precomputed (rainbow table) attacks.

## Simple ciphers

A Caesar cipher shifts each letter by a fixed amount: with shift 3, CAT becomes FDW. It is trivially broken, but it illustrates keys and substitution.

<Note title="Key management">
Encryption is only as strong as key protection. A key stored next to the data protects almost nothing.
</Note>

<WorkedExample title="Choose the tool">
A school wants to detect whether anyone changes exam files after they are finalized. Encryption or hashing?

1. Detecting changes is an integrity goal.

**Answer:** hashing: record each file's hash and compare later.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

Using a Caesar cipher with a shift of 7 (A → H), what is the ciphertext for `SECURE`?

**Answer:** `ZLJBYL`

**Why:** Shift each letter forward by 7.

**Working:** SECURE → ZLJBYL with shift 7.

**Mistakes to avoid**

- `LXVNKX`: Check the direction of the shift.
- `AMKCZM`: The shift is 7, not 8.
- `LYBJLZ`: A Caesar cipher substitutes letters; it does not reorder them.

### Worked exam question 2

The ciphertext `XJWAJW` was produced by a Caesar cipher with a shift of 5 (A → F). What is the plaintext?

**Answer:** `SERVER`

**Why:** Shift each letter back by 5.

**Working:** XJWAJW ← SERVER with shift 5.

**Mistakes to avoid**

- `COBFOB`: Check the direction of the shift.
- `RDQUDQ`: The shift is 5, not 6.
- `REVRES`: A Caesar cipher substitutes letters; it does not reorder them.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** A team wants to confirm that a downloaded software installer has not been altered. Which technique should it use?

**A.** Compare the file's hash with the hash published by the vendor. Hashes verify integrity.

**Q.** Why should error messages on a website be generic, such as 'Something went wrong'?

**A.** Detailed errors can reveal database or system details useful to attackers. Details belong in private logs.

**Q.** A company stores user passwords. How should they be stored?

**A.** As salted hashes using a slow password-hashing algorithm. Hashes cannot be reversed, and salts defeat precomputed tables.

**Q.** Which statement correctly contrasts hashing and symmetric encryption?

**A.** Encryption can be reversed with the key; hashing is one-way. That is the key difference.

**Q.** Employees who move to new departments keep access to their old department's files. What practice fixes this?

**A.** Regular access reviews that remove permissions no longer needed. This prevents privilege creep.

**Q.** Access to hospital records is granted based on whether a user is a nurse, doctor or billing clerk. Which access control model is this?

**A.** Role-based access control. Permissions follow the job role.

**Q.** What is the most effective defense against SQL injection?

**A.** Parameterized queries (prepared statements). They keep user input separate from the query's code.
