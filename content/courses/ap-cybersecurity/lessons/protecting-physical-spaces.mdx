Physical security uses layers from the perimeter inward.

| Layer | Controls |
| --- | --- |
| perimeter | fences, gates, bollards, lighting |
| building entry | badges, guards, turnstiles, vestibules |
| rooms | locks, biometric readers, visitor logs |
| devices | cable locks, locked server racks, screen privacy filters |
| data | encrypted drives, secure disposal, clean-desk policy |

Controls can **deter** (signs, lighting), **prevent** (locks), **detect** (cameras, alarms) or **correct** (incident response).

Environmental controls (fire suppression, HVAC, power backup) protect availability.

<Note title="Match the control to the threat">
Cameras detect but do not prevent. Choose controls that address the specific vulnerability.
</Note>

<WorkedExample title="Choose controls">
A server room is behind a door with a keypad whose code many staff share. What two improvements help most?

1. Shared codes cannot be traced to a person.
2. Badge or biometric readers log individuals; a camera records entries.

**Answer:** replace the keypad with individual badge or biometric access, and add logging or video.
</WorkedExample>

## On the practice exams

These are the facts and ideas the practice exams ask about this topic, each with the answer and the reason. If you can answer all of them without looking, you are ready for this topic on the exams.

### Facts and ideas the exams test

Cover the answers and test yourself.

**Q.** How is a sign warning that the area is under video surveillance best classified, by control category and function?

**A.** Physical, deterrent. It is a physical control whose purpose is to discourage attackers. A sign warning that the area is under video surveillance: physical, deterrent control.

**Q.** How is security cameras in a server room best classified, by control category and function?

**A.** Physical, detective. It is a physical control whose purpose is to discover incidents. Security cameras in a server room: physical, detective control.

**Q.** How is locks on network closets best classified, by control category and function?

**A.** Physical, preventive. It is a physical control whose purpose is to stop incidents. Locks on network closets: physical, preventive control.

**Q.** How is an acceptable use policy employees must sign best classified, by control category and function?

**A.** Managerial, preventive. It is a managerial control whose purpose is to stop incidents. An acceptable use policy employees must sign: managerial, preventive control.

**Q.** How is an intrusion detection system that alerts on suspicious traffic best classified, by control category and function?

**A.** Technical, detective. It is a technical control whose purpose is to discover incidents. An intrusion detection system that alerts on suspicious traffic: technical, detective control.

**Q.** How is annual security awareness training best classified, by control category and function?

**A.** Managerial, preventive. It is a managerial control whose purpose is to stop incidents. Annual security awareness training: managerial, preventive control.

**Q.** How is reviewing badge access logs each week best classified, by control category and function?

**A.** Managerial, detective. It is a managerial control whose purpose is to discover incidents. Reviewing badge access logs each week: managerial, detective control.

**Q.** How is a firewall blocking unused ports best classified, by control category and function?

**A.** Technical, preventive. It is a technical control whose purpose is to stop incidents. A firewall blocking unused ports: technical, preventive control.

**Q.** How is restoring files from backups after a ransomware attack best classified, by control category and function?

**A.** Technical, corrective. It is a technical control whose purpose is to restore after an incident. Restoring files from backups after a ransomware attack: technical, corrective control.

**Q.** Which is an example of a deterrent physical control?

**A.** Bright lighting and visible warning signs around a facility. They discourage attempts.

**Q.** Employees often hold the secure entrance door for people behind them. Which control best addresses this?

**A.** An access control vestibule (mantrap) or turnstile that admits one person per badge. It physically prevents tailgating.

**Q.** Visitors in a lobby can see an employee typing passwords at the reception computer. What vulnerability is this, and what is a fix?

**A.** Shoulder surfing; reposition the screen or use a privacy filter. Watching screens and keyboards reveals secrets.

**Q.** Old hard drives from retired laptops are placed in a dumpster. What is the best control?

**A.** Securely wipe or physically destroy the drives before disposal. Data on discarded drives can be recovered.

**Q.** An unknown small device is found plugged in between a keyboard and a computer. What is it most likely?

**A.** A hardware keylogger recording keystrokes. Such devices capture everything typed.
