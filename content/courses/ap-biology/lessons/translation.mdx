Ribosomes translate mRNA into a polypeptide.

1. **Initiation**: the ribosome assembles at the start codon AUG with a methionine-carrying tRNA.
2. **Elongation**: tRNAs with matching anticodons bring amino acids; peptide bonds form; the ribosome moves along one codon at a time (5′ to 3′).
3. **Termination**: a stop codon (UAA, UAG, UGA) causes release of the polypeptide.

The code is **redundant**: most amino acids have more than one codon. It is nearly **universal**, which is why bacteria can make human proteins from inserted genes.

| Codon | Amino acid | Codon | Amino acid |
| --- | --- | --- | --- |
| AUG | Met (start) | UUU | Phe |
| GCU | Ala | AAA | Lys |
| UGG | Trp | GGC | Gly |
| CCU | Pro | UAA | stop |

<Note title="Viruses">
Retroviruses such as HIV use reverse transcriptase to make DNA from their RNA genome, which is then inserted into the host's DNA.
</Note>

<WorkedExample title="Translate">
Using the table, translate the mRNA 5′-AUGGCUAAAUGGUAA-3′.

1. Codons: AUG GCU AAA UGG UAA.
2. Met, Ala, Lys, Trp, stop.

**Answer:** Met–Ala–Lys–Trp.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

*Selected codons*

| mRNA codon | Amino acid |
| --- | --- |
| AUG | Met |
| CAU | His |
| GGU | Gly |
| UAG | stop |
| UUC | Phe |

The template strand of a DNA segment reads 3′-TACGTACCAAAGATC-5′. Using the codon table, what polypeptide does it encode?

**Answer:** Met–His–Gly–Phe

**Why:** Transcribe (complementary, with U for T), then read codons from AUG.

**Working:** mRNA: 5′-AUGCAUGGUUUCUAG-3′. Codons AUG CAU GGU UUC UAG give Met–His–Gly–Phe, then stop.

**Mistakes to avoid**

- Phe–Gly–His–Met: mRNA is read 5′ to 3′, starting at AUG.
- His–Gly–Phe: Translation starts with the methionine of AUG.
- Met–His–Gly–Phe–stop: A stop codon does not add an amino acid.
