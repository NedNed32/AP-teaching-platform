DNA, and in some viruses RNA, is the hereditary material.

| | Prokaryotes | Eukaryotes |
| --- | --- | --- |
| chromosomes | usually one, circular | several, linear |
| location | nucleoid | nucleus |
| packaging | fewer proteins | wrapped around histones |
| extra DNA | plasmids | mitochondrial and chloroplast DNA |

Base pairing (A–T, G–C; A–U in RNA) allows information to be copied and read. Plasmids can carry genes, such as antibiotic resistance, that pass between bacteria.

<Note title="Purines and pyrimidines">
Every base pair joins a two-ring purine (A, G) with a one-ring pyrimidine (C, T, U), keeping the helix a constant width.
</Note>

<WorkedExample title="Complementary strand">
Write the complementary DNA strand for 5′-AGGTCA-3′.

1. Pair each base: A–T, G–C.
2. Reverse the direction so it reads 5′ to 3′.

**Answer:** 5′-TGACCT-3′.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

One strand of DNA reads 5′-CAAATTAA-3′. What is the sequence of the complementary strand, written 5′ to 3′?

**Answer:** 5′-TTAATTTG-3′

**Why:** Pair each base and reverse the direction, because strands are antiparallel.

**Working:** The complement of 5′-CAAATTAA-3′ is 3′-GTTTAATT-5′, written 5′-TTAATTTG-3′.

**Mistakes to avoid**

- 5′-GTTTAATT-3′: The complementary strand is antiparallel; written 5′ to 3′ it is reversed.
- 5′-UUAAUUUG-3′: DNA contains T, not U.
- 5′-AATTAAAC-3′: Each base must be paired, not just reversed.
