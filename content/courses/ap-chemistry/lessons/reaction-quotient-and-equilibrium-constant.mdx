For $$\ce{aA + bB <=> cC + dD}$$:

$$K_c = \frac{[\ce{C}]^c[\ce{D}]^d}{[\ce{A}]^a[\ce{B}]^b} \qquad K_p \text{ uses partial pressures}$$

Pure solids and liquids are omitted. Q uses the same expression with current (not necessarily equilibrium) values.

<Note title="Products over reactants">
Always products in the numerator, each raised to its coefficient.
</Note>

<WorkedExample title="Write K">
Write Kc for $$\ce{CaCO3(s) <=> CaO(s) + CO2(g)}$$.

1. Solids are omitted.

**Answer:** $$K_c = [\ce{CO2}]$$.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

For $$\ce{A(g) + B(g) <=> 2C(g)}$$, K = 6.6. A mixture has [A] = 0.4 M, [B] = 0.9 M and [C] = 0.2 M. In which direction will the reaction proceed?

**Answer:** It proceeds forward, toward products, because Q = 0.111

**Why:** Q = [C]²/([A][B]) = 0.111, which is less than K.

**Working:** Q = 0.2²/(0.4·0.9) = 0.111; K = 6.6.

**Mistakes to avoid**

- It proceeds in reverse, toward reactants, because Q = 0.111: If Q is less than K, the reaction proceeds forward.
- It is at equilibrium, because Q = K: Q = 0.111 ≠ 6.6.
- It proceeds forward, toward products, because Q = 0.556: Square [C], since its coefficient is 2.
