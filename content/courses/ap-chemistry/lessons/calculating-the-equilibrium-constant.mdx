Substitute equilibrium values into the K expression. If given initial values and one equilibrium value, use an ICE table to find the others first.

<Note title="Use equilibrium values only">
Initial concentrations do not go into K unless the system started at equilibrium.
</Note>

<WorkedExample title="ICE to K">
1.00 M H₂ and 1.00 M I₂ react; at equilibrium [HI] = 1.56 M. Find K for H₂ + I₂ ⇌ 2HI.

1. x = 0.78; [H₂] = [I₂] = 0.22 M.
2. $$K = 1.56^2/(0.22)^2$$.

**Answer:** about 50.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

For $$\ce{H2(g) + I2(g) <=> 2HI(g)}$$, initial [H₂] = 0.5 M and [I₂] = 1 M, with no HI. At equilibrium, [HI] = 0.48 M. What is K?

**Answer:** $$1.17\ \mathrm{}$$

**Why:** x = 0.24; [H₂] = 0.26, [I₂] = 0.76.

**Working:** K = (0.48)²/((0.26)(0.76)) = 1.17.

**Mistakes to avoid**

- $$2.43\ \mathrm{}$$: Square [HI] (coefficient 2).
- $$0.461\ \mathrm{}$$: Use equilibrium, not initial, concentrations.
- $$0.291\ \mathrm{}$$: [HI] = 2x.
