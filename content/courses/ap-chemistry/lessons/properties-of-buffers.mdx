Buffers work because both components react: $$\ce{A- + H3O+ -> HA + H2O}$$ and $$\ce{HA + OH- -> A- + H2O}$$.

pH changes only slightly because the ratio $$[\ce{A-}]/[\ce{HA}]$$ changes slightly.

<Note title="Particle-level explanation">
Name the species that reacts with the added acid or base, and write the reaction.
</Note>

<WorkedExample title="Explain">
Why does adding NaOH to an NH₃/NH₄⁺ buffer barely change the pH?

1. OH⁻ reacts with NH₄⁺ to form NH₃ and H₂O.

**Answer:** the added base is consumed by NH₄⁺.
</WorkedExample>

## On the practice exams

These are the kinds of questions the practice exams ask about this topic. Each has a full answer, the reasoning, and the reason each wrong option is wrong. If you can do all of them without looking, you are ready for this topic on the exams.

### Worked exam question 1

A weak acid HA has pKa = 7.1. In a solution at pH 4.5, which statement is correct?

**Answer:** [HA] is greater than [A⁻]

**Why:** Below the pKa, the protonated form dominates.

**Working:** pH 4.5 &lt; pKa 7.1.

**Mistakes to avoid**

- [A⁻] is greater than [HA]: Compare pH with pKa.
- [HA] equals [A⁻]: Only at pH = pKa.
- Only HA is present: Both forms are present.
